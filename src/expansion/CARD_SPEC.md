# 카드 작성 사양 (확장 작업용, 2026-11-13)

새 카드(기본 추가)와 복원 카드(지운 2,312개 손보기)를 쓰는 사람·에이전트가 보는 문서예요.
기준은 지금 앱에 들어 있는 카드(`src/build/data_app.json`)예요. 모르는 게 있으면 비슷한 기존 카드를 열어 보고 똑같이 맞춰요.

## 0. 배우는 사람
- 한국어 모국어. N5·N4를 반쯤 아는 수준에서 시작해 이 앱 단어만으로 BJT를 준비함. 한자어는 한국 한자음으로 뜻을 잡는 게 제일 빠름.
- 회독(빠르게 여러 번)으로 외움. 처음 볼 때 '아, 그래서 이 뜻이구나'가 나와야 함.
- 읽기는 **히라가나**만(한글 음차 금지, 카드 설명에 가타카나 읽기 금지 — 가타카나어 자체는 예외).

## 1. 넘겨주는 꼴 (JSONL, 한 줄에 카드 하나)
```json
{"id": 9886, "w": "入院", "r": "にゅういん", "m": "입원", "t": "K", "c": "gen",
 "ko": "입원", "kr": [["入","にゅう"],["院","いん"]],
 "p": "부재 이유 「入院しております」=입원해 있습니다. 반대 退院(たいいん)", "y": "", "o": "",
 "st": "入(들 입)+院(집 원): 병원(院)에 들어감(入) → 입원. 한국어 '입원'과 같은 말. 반대 退院.",
 "e": [
  {"s": "tel", "j": "[部長|ぶちょう]は、[先週|せんしゅう]から{[入院|にゅういん]}しております。", "k": "부장은 지난주부터 입원해 있습니다.",
   "g": [["部長","부장"],["先週","지난주"]]},
  {"s": "talk", "j": "{[入院|にゅういん]}したとき、[会社|かいしゃ]のみんながお[見舞|みま]いに[来|き]てくれました。", "k": "입원했을 때 회사 사람들이 다 같이 병문안을 와 주었습니다.",
   "g": [["時","때·시"],["会社","회사"],["みんな","모두"],["お見舞い","병문안·위문"],["来る","오다"],["くれる","(남이 나에게) 주다"]]}
 ],
 "pr": ["退院"]}
```
- 쓰는 사람이 채우는 칸: `id w r m t c ko kr p y o st e pr`. 도구가 만드는 칸: `hw`(표제어 루비) · `kj`(한자 목록) · 예문 `t`(루비 뺀 글) · `ord`/`bn`(순서) · `pr`(표제어 → id).
- **복원 카드**는 옛 카드(`old_words_2312.json`)를 그대로 가져와 고칠 것만 고침. `id`는 옛 번호 그대로(바꾸면 음성 파일·기록이 어긋남).
- **기본 추가 카드**의 `id`는 작업 시트에 적힌 값(9000 + 기본 번호)을 그대로.

## 2. 칸별 규칙
| 칸 | 규칙 |
|---|---|
| `w` | 보통 쓰는 현대 표기. 옛·드문 한자 표기는 업무 문서에서 쓰는 꼴로(繋ぐ → つなぐ, 押える → 押さえる, 寧ろ → むしろ — 원래 한자는 `p`에) |
| `r` | 히라가나(가타카나어는 가타카나). 업무에서 쓰는 표준 읽기. 明日는 あす |
| `m` | 짧은 한국어 뜻(22자 이하). 여러 뜻이면 `·`로 |
| `t` | 본편: 복원 카드는 옛 등급 A/B 그대로 / 기본 추가는 `K` |
| `c` | org mtg sch tel doc deal money sales graph hr trouble verb formal kata keigo it gen (가타카나어는 전부 kata) |
| `ko` | 표제어 한자의 한국 한자음을 이어 씀. 2자 이상이면 두음법칙(来月 → 내월, 労働 → 노동). 한자가 없으면 빈칸 |
| `kr` | 한자 하나하나의 이 단어 속 읽기(히라가나). 이어 붙이면 표제어 한자 부분 읽기와 같아야 함(連濁·촉음 반영: 日本 → [["日","に"],["本","ほん"]], 一緒 → いっ+しょ) |
| `p` | BJT 포인트(한국어 70자 안): 어디서 어떤 꼴로 나오는지 · 짝말 · 헷갈림 주의. 소리가 같은 다른 말(感心/関心, 公演/講演, 改訂/改定)은 여기서 경고 |
| `y` | 바꿔 말하면: 쉬운 일본어 풀이나 비슷한 말. 쓸 게 없으면 빈칸 |
| `o` | 가타카나어만: 영어 원어 + 뜻, 예 `schedule(일정)` |
| `st` | 이야기(100자 안) — 아래 3절 |
| `e` | 예문 2개(뜻·쓰임이 확실히 다른 중요한 용법이 있을 때만 3개) — 아래 4절 |
| `pr` | 헷갈리는 짝(있을 때만): 표제어 글자로 적음(같은 표기가 둘이면 `No.번호`/`B번호`) |

## 3. 이야기 `st`
- 한자어: `漢(훈 음)+字(훈 음): 두 뜻이 어떻게 합쳐지는지 → 단어 뜻.` 한국어와 같으면 `한국어 '○○'와 같은 말.`
  - `確(확실할 확)+認(알 인): 확실하게 알아봄 → 확인. 한국어 '확인'과 같은 말.`
  - `取(가질 취)+引(끌 인): 물건을 쥐고 끌어와 주고받음 → 거래. 한국어 '취인'은 안 쓰니 '거래'로 외우기.`
- 한자 + 가나: 부분마다 풀이. `見(보다)+合わせる(맞추다): 상황을 보고 맞춰 보며 일단 멈춤 → 보류하다.`
- 가나만: 뒤에 있는 한자나 생생한 고리. `する의 겸양어. 한자로 致す(이를 치) — 내가 정성을 다해 해 드림.`
- 가타카나: 영어 원어 + 고리(`o`에도 원어).
- 경어·정형 표현: 짜임을 보여 줌. `少々(조금)+お待ち(기다림)+ください(주세요) → '잠깐 기다려 주세요'의 가장 정중한 형태.`
- 훈음은 표준 훈음(한자 카드의 `h`와 같게). 지어낸 어원·역사 금지(확실하지 않으면 '옛 풀이로는'). 한국어에 「」 따옴표 쓰지 않음.
- 사용자 기준(한자 카드에서 확인됨): 추상적 연결·소리 놀이 금지, 장면만 보고 뜻이 보여야 함, 직관적일수록 좋음.

## 4. 예문 `e`
- 장면 `s`: tel(전화) mtg(회의) talk(사내 대화) visit(방문·응대) biz(일반 업무) graph(수치 설명) doc(자료) mail(메일) notice(공지) report(보고·규정) news(경제 기사). 앱에서 청해/청독해/독해 표시로 바뀜.
- 자연스럽고 짧은 비즈니스 일본어 12~35자(최대 45자). 대화는 です・ます, 공지·문서는 문어체.
- **직접 지은 문장만.** 시험 문제집(특히 공식 모의)의 문장을 옮기거나 비슷하게 바꿔 쓰지 않음.
- 같은 카드의 두 예문이 같은 뜻·같은 꼴이면 안 됨. 다른 카드 예문과 거의 같은 문장도 안 됨(정형 인사·사과 표현은 예외).
- `{...}`는 정확히 한 군데, 표제어가 나온 자리(활용 꼴 가능: `{伺い}ます`, `{確認し}てください`). 표제어 한자를 순서대로 다 담아야 함. 가나 단어는 그 말로 시작.
- 숫자는 아라비아 숫자(3月10日, 20%, 5,000円). **숫자 바로 뒤 조수사에는 루비를 달지 않음**(지금 카드 715 : 12) → `1週間`, `3階`, `5人`.
- 루비 `j`: 한자가 이어진 덩어리마다 `[漢字|よみ]`, 送り仮名는 밖에(`お[送|おく]りいただいた`). 표제어도 루비를 담(`{[受領|じゅりょう]}`). 루비를 빼고 `{}`를 지운 글이 그대로 문장이어야 함.
- 문맥에 따라 읽기가 갈리는 한자를 특히 조심: 方(かた/ほう) · 何(なに/なん) · 日本(にほん) · 後(あと/のち/ご) · 上 · 中(なか/ちゅう/じゅう) · 間 · 一日(いちにち/ついたち) · 今日(きょう/こんにち) · 明日(あす로 통일) · 人(じん/にん/ひと) · 私(업무 문장에서 자기를 낮출 땐 わたくし) · 行(い/おこな) · 外国人(じん) · 予定通り(どおり) · 親会社·○○会社(がいしゃ) · 市場(しじょう/いちば) · 人気(にんき) · 通(とお/かよ) · 怒(おこ).
- 번역 `k`: 자연스러운 한국어(직역 금지).
- 단어 풀이 `g`: 예문 속 낱말 중 배우는 사람이 모를 수 있는 내용어를 사전형으로 `[표제, 짧은 뜻]`.
  - 빼는 것: 그 카드의 표제어, 숫자, 고유명사, 그리고 지금 카드들이 한 번도 풀지 않은 기초어 — する いる この なる ある こと おる ござる そう よう その 私 いい よる 知る くる いう うち もの いつ ところ それ これ ほう なに, 숫자 뒤 조수사(円 割 度 階 週間 か月).
  - 경어 보조동사는 넣고 표시: `["いただく","~해 주시다(겸양)"]`, `["いたす","하다(겸양)"]`, `["くださる","주시다"]`.
  - 같은 말은 늘 같은 뜻으로: `gloss_dict.json`(지금 카드 4,994문장의 풀이 2,504개, 많이 쓴 순)을 먼저 찾아 그 뜻을 씀. 문맥상 다른 뜻일 때만 바꿈.
  - 풀이 표제가 다른 카드 표제어와 같으면 앱이 그 카드로 연결해 주니 표기를 맞춤.

## 5. 기본 추가 카드 고르기
- 대상: `basic_add.json`(JLPT N5·N4 목록 중 앱에 없는 471개, 빈도 순) + `n3n2_missing.json` 앞쪽의 기초 인사·정형 표현(ありがとう・こんにちは・おはよう・いただきます・お願いします・どういたしまして・お先に・お待ちください 등 — 실제로는 N5급).
- 빼는 것(작업 시트에 이유와 함께 적어 둠): 낱자 조각·조사·문법 항목(あ・御・堅 같은 것), 지금은 안 쓰는 말(電報・汽車・看護婦→看護師로 쓰거나 뺌), 앱에 이미 있는 말의 다른 표기(知合い = 知り合い).
- 아주 기초(この・その・これ・何・はい 등)도 사용자가 '기초는 전부'라고 했으니 넣음. 예문은 BJT 장면으로.

## 6. 복원 카드 손보기 (옛 카드 → 지금 수준)
옛 카드는 10/4에 만들고 그 뒤 검수를 안 받음. 지금 카드와 비교해 빠진 것:
- 예문 `g`(단어 풀이)가 없음 → 4절대로 채움.
- 루비·읽기 규칙이 10/7~10/22에 정해진 것(明日=あす, 私=わたくし, 会社=がいしゃ, 숫자 뒤 조수사 루비 없음 등) → 맞춤.
- `ko` 두음법칙, `st` 훈음이 한자 카드(`h`)와 같은지, `p`·`y`·`o`가 위 규칙에 맞는지.
- 다른 카드(지금 2,331 + 다른 복원 카드)와 거의 같은 예문 → 바꿈(바꾸면 그 예문 음성도 다시 만들어야 함 → 작업 기록에 적기).

## 7. 검수 (작성자와 다른 사람·에이전트가)
- 파일을 고치지 말고 TSV로: `id	field	current	suggested	reason`. field = r m p y ko st kr j0 j1 k0 k1 g0 g1 jtext0 jtext1 …
- 진짜 오류만: 틀린·비표준 읽기, 틀리거나 오해를 부르는 뜻, 오역, 부자연스러운 일본어, 틀린 어원, 틀린 한국 한자음, 문맥과 다른 루비, 빠진·틀린 풀이. 취향 문제는 적지 않음.
- 끝에 `#SUMMARY 본 카드 n · 오류 n`.
- 지금까지 검수에서 많이 나온 오류: 지어낸 훈음·음독, 사실처럼 단정한 어원, 方·何·中·後 루비, 会社(がいしゃ), 숫자+조수사 읽기, 성별 고정관념 장면, 같은 예문 반복, 풀이 빠짐.
