# rvn3c 판정 (n3an01 35장 + n3an02 19장, 11/13)

- 20467 空(から): **유지(카드 자체는 고칠 것 없음).** m「(속이) 빔·빈 것」, p는 から로만 읽는 꼴(空の箱·空にする·空メール)과 「같은 글자 空(そら)=하늘, 空く(あく)=비다」 경고, st는 두 읽기를 빌 공 하나로 이어 줌 → 차이는 분명함. pr「B258」은 CARD_SPEC §2 꼴이고 append_cards.py가 bn 258 → 10020 空(そら)로 바꿔 줌(20467은 이미 ALLOW_DUP). 빈 곳은 반대쪽: 앱 10020의 p「단독 「空」=하늘(そら)」은 이제 틀린 말이고 20467로 돌아오는 pr도 없음(一日 9246↔9307, 来る 9050→2102는 양쪽 다 경고). 10020 p·pr 제안을 review.tsv 끝 2줄에 넣음(54장 밖이라 오류 수에 안 셈, 음성 비용 없음).
- 20070 中学: **유지 + p 고침.** 다른 표기가 아니라 꼴·읽기가 다른 말(ちゅうがく / ちゅうがっこう)이라 CARD_SPEC §5 제외 대상 아님. N3 순위표 자체 항목(N3 No.469)이고, 예문(同級生·中学受験)이 10062 中学校 예문(職場体験·通い始めます)과 안 겹침. 다만 p의 「이력에선 「中学」」은 틀림: 이력서(履歴書)에는 정식 이름 「〇〇中学校」로 씀 → review.tsv. (선택) 10062 pr에 20070 추가. 참고: 앱 10003 高校 p「이력서 「〇〇高校卒業」」도 같은 잘못(이력서는 高等学校). 이번 범위 밖이라 오류 수에 안 셈.
- 20234 作 e1 豊{作}: **괜찮음.** 앱에 한 글자 표제를 낱말 속에서 괄호로 묶은 예가 많음({株}価·消費{税}·成功{例}·達成{率}·生産{量}). 지금 일본어에서 '작황' 뜻의 作는 따로 쓰는 일이 드물고(보통 作柄) 豊作·不作 안에서 만나므로, 이 문장이 실제 쓰임을 보여 줌. m「(농사의) 작황」, st「豊作(풍작)의 作」와도 맞음. g에서 豊作을 통째로 푼 것도 괜찮음(豊 혼자는 낱말이 아님). 단, 같은 카드 e0은 앱 10160 絵 e0과 같은 장면이라 교체(review.tsv).
- 20644 負け e1 私=わたし: **괜찮음.** CARD_SPEC §4의 わたくし는 업무에서 자기를 낮출 때 쓰는 규칙. 이 문장은 동료끼리 점심 내기라서 わたくし는 오히려 딱딱함. 앱에도 talk 장면의 わたし가 있음. 같은 이유로 20209 男子 e1, 20387 少女 e1의 わたし도 그대로.

## 숫자 세는 법
`#SUMMARY 본 카드 54 · 오류 6` = 54장 안의 문제 6건(review.tsv 14줄: 예문 교체는 s/j/k/g를 따로 적음). 10020 2줄은 이 수에 안 넣음. 교체한 문장 3개는 내 폴더에서 check_cards.py(--others 포함)를 돌려 봄. 경고가 새로 생기지 않았고 비슷한 문장도 없음.
