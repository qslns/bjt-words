# rvn3b 판정 (n3ar01, 47장)

- 3443 筋 e0 루비 通(とお): **맞음.** 筋が通る = すじがとおる(조리가 서다). 옛 かよ(通う)는 틀린 읽기였음. 글은 그대로라 review.tsv에 줄 없음(옛 음성이 かよって로 읽혔는지만 따로 확인).
- 1332 e0 / 1307 e0 「チャレンジ精神のある方」: **한쪽 교체 → 1332 e0.** 1332 e0의 내용 전체(チャレンジ精神のある方)가 1307 e0 안에 그대로 들어 있고 둘 다 구인 광고(No.185·No.211, 가까운 순번). 精神 쪽을 「仕事の量より、人間関係のほうが精神的につらいです。」(talk)로 바꾸면 p의 「精神的」 용법 예문이 생기고, 1307은 チャレンジ精神 연결을 그대로 가짐. 새 음성 1개. 전체 칸은 review.tsv.
- 3486 e1 / 3748 e1 같은 틀: **한쪽 교체 → 3748 e1.** 「当社の[부품/센서]は、[우주개발/농업]の分野でも使…」 틀이 같고, 두 카드 e0도 「大手〜への参入」으로 겹쳐 한 쌍이 찍어 낸 듯 보임. 3748 e1을 「実家は、長野で農業をしています。」(talk)로 바꿈(덱·작업 파일과 겹침 없음; 「この地域は農業が盛ん」은 덱 9508 「この地域は、自動車工業が盛んだ。」와 겹쳐서 안 씀). e0끼리는 구조가 달라(発表した/増えている) 그대로 둠. 새 음성 1개.
- 3418 首相 p: **정확함.** 헌법·내각법상 정식 직함은 内閣総理大臣, 흔히 総理大臣·総理·首相으로 줄여 부름(首相은 통칭). 고칠 것 없음. st의 「相=外相처럼 장관」도 맞음.
