# rvn3x2 표제어 꼴 판정 (50장)

- 陣·気味·旧·溜まる 같은 접사 전용어·상용 밖 표기: 이 50장에는 없음 → 판정할 것 없음.
- 額(がく): 유지 — 「額が大きい」「この額では」처럼 단독으로 쓰고(액자 뜻도 단독), e0 단독·e1 〜額(お支払い額)으로 두 쓰임을 다 보여 줌. (같은 한자 ひたい=이마를 p에 덧붙이는 건 선택)
- 末(すえ): 유지 — 「検討の末」「今月の末」처럼 단독 명사로 씀. 붙여 쓰는 〜末(まつ)은 p가 이미 알려 줌(3月末=まつ), 月末·年度末은 앱에 따로 있음.
- 週(しゅう): 유지 — 「週に1回」「週3日」처럼 단독으로 씀. 今週·来週·〜週間은 앱에 따로 있음.
- 賞(しょう): 유지 — 「賞をもらう」「賞を取る」처럼 단독으로 씀. 두 예문이 다 〜賞 합성어(デザイン賞·社長賞)이지만 뜻은 바로 보여서 고칠 정도는 아님.
- なし: 가나 유지 — 無し도 상용 표기지만 서류·표에서는 「変更なし」「該当なし」처럼 가나가 보통(p에 이미 적혀 있음).
- 疲れ: 유지 — 疲れる(앱에 있음)의 명사형이지만 「疲れが取れない」「疲れがたまる」처럼 따로 쓰는 N3 단어. pr로 疲れる에 연결됨.
- 読み·残り: 유지 — 동사의 명사형이 독립 명사로 쓰임(読みが甘い, 残りわずか).
- 我々: 유지 — 々 표기가 표준.
- 예문 속 표기: 肩がこる(凝る는 상용이지만 가나도 보통)·なで下ろす(撫는 상용 밖이라 가나가 맞음)·手がける·〜をめぐる — 그대로 둠.
