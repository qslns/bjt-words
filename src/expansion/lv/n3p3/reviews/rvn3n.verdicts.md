# rvn3n 판정 (n3cn01 out.jsonl 37장, N3 No.1,001–1,500 새 카드, 11/15)

## 과제에 적힌 의문 (한 줄씩)

- **降伏 (幸福 p): p 그대로 + pr에도 넣음.** こうふく 완전 동음어 경고로 맞음. 降伏는 같은 3부 새 카드(n3cn03 20563)라 곧 앱에 들어옴. 降伏 카드 pr은 비어 있어 이쪽에서 이어야 둘이 연결됨 → review.tsv 20504 pr ["幸せ","降伏"]. append_cards.py는 같이 붙이는 카드 표제도 찾고, 못 찾으면 「pr 못 찾음 → 뺌」 로그를 남겨 relink_pr.py가 나중에 이음.
- **灰 (肺 p): p 그대로 + pr에도 넣음.** はい 동음어 명사, 4부 새 카드(n3dn01 20616). 4부를 붙이기 전엔 append가 빼고 로그를 남김 → relink로 이어짐. 같은 p의 はい·〜杯는 기초어·접미어라 p 경고로 충분(pr에 안 넣음) → review.tsv 20671 pr ["灰"].
- **〜敗: 실제로는 어느 카드의 p에도 없음** (肺 p는 「はい(네)·〜杯(~잔)·灰(재)」만 씀). 시트 homophones에만 있음. 4부 새 카드(n3dn03 20672)지만 승패를 세는 접미어(3勝2敗)라 肺와 헷갈릴 일이 적고, 그 카드 pr이 이미 〜杯를 잇고 있음 → 넣지 않아도 됨.
- **動詞 (同志 p): p 그대로 + pr에도 넣음.** どうし 동음어(〜同士·同志·動詞 셋), 4부 새 카드(n3dn02 20595). 動詞 카드 pr엔 〜同士만 있어 同志와는 안 이어짐 → review.tsv 20669 pr ["〜同士","動詞"]. 灰와 같은 방식으로 이어짐.
- **pr 去る (猿): 유지.** RESTORE_BRIEF는 pr 대상으로 「복원 목록」을 허용함. 去る는 같은 N3 3부 복원 카드(n3cr05 1250 「떠나다·지난」)라 같이 붙이면 바로 이어지고, 아니면 relink. 猿과 さる 완전 동음이라 짝으로 맞음.
- **pr 現れる (現れ): 유지.** 같은 3부 복원 카드(n3cr04 1358). 명사-동사 짝이라 앱의 飾り→飾る, 貸し→貸す와 같은 꼴.
- 위 pr 3줄(20504·20669·20671)은 오류가 아니라 이 판단에서 나온 것이라 SUMMARY 오류 5에 넣지 않음.

- 통학 e0 「高校には、毎日自転車で30分かけて通学していました」 ↔ 앱 9684 自転車 e0 「天気がいい日は、自転車で通勤しています」·2452 通勤 e0: 통학 수단·시간은 이 표제의 기본 장면이고 서술 틀이 다름 → 그대로.
- 菌 e1 「ヨーグルトの菌には…働きがあります」 ↔ 앱 20339 森林 e1 「森林浴には、ストレスを減らす効果があるそうです」: 「〜には〜효과」 꼴만 같고 장면이 다름 → 그대로. 婚約 e0 ↔ 앱 9345 入院 e1 (회사 사람들 반응): 서술(喜んでくれた / お見舞いに来てくれた)이 달라 그대로. ドラマ e0 ↔ 同志 e0 (둘 다 「…勉強(会)を始めました」로 끝남): 장면이 달라 그대로.
