# rvn3o 판정 (n3cn02 새 카드 37장, 11/15)

- 20471 かわいそう 当て字: **작성자가 맞음, st의 可哀想 유지.** 사전(JMdict/jisho)의 대표 표기는 可哀想(当て字)이고, 可哀相·可哀そう도 같은 当て字. 시트 메모의 可愛는 可愛そう(かわい+そう에서 온 드문 변형 표기)일 뿐 대표 当て字가 아님. 어느 표기든 상용 읽기 밖이라 표제를 가나로 둔 것도 맞음 (https://jisho.org/search/かわいそう).
- 20468 殻 pr 「空」: **맞음, 空(から) 20467로 이어짐.** append_cards의 표제→id 표는 같은 표기가 둘이면 뒤 카드가 남음. data_app.json에서 20467 空 から가 10020 空 そら 뒤에 있어 「空」→20467 「(속이) 빔·빈 것」으로 감. 같은 방식으로 쓴 3081 空っぽ의 pr 「空」도 지금 앱에서 20467로 이어져 있음. 짝 이유도 맞음: 殻와 空는 둘 다 から이고 뜻이 '속이 빈 겉껍데기'와 '빈 것'으로 가까움. p는 '동음'이라고만 하고 어원은 단정하지 않음. 순서가 바뀔 걱정을 없애려면 pr에 숫자 20467을 바로 적어도 됨(append_cards가 정수 id를 그대로 받음).
- 20224 沖 훈음: **'깊을 충' 유지(최종 파일 kanji_h_final_1115.json과 같고, 카드 st도 이미 깊을 충).** 어문회 대표 훈은 '화할 충'임(나무위키: 화할·빌·찌를, https://namu.moe/w/沖). 하지만 '깊을'도 한자 자료에 실린 훈이라 지어낸 것이 아님(k-calc 인명 한자: 沖 '물탈·깊을', https://k-calc.com/hanja/chung). 게다가 おき(해안에서 멀리 나간 깊은 바다)와 바로 이어져서 '화할'보다 기억 고리로 좋음.
