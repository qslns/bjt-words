# rvn2w — n2cn04 (N2 3부 No.1224–1290) 작성자 메모 판정

- **ウーマン (No.1257, 20317)** → 접미 카드 `〜ウーマン`으로 바꿈. 혼자는 거의 안 쓰고 キャリア·ビジネス 같은 말 뒤에만 붙음 — REVIEW_LV §5·LV_NOTE3 §6이 말하는 접미 표제. 두 예문이 이미 `キャリア{ウーマン}`·`ビジネス{ウーマン}` 꼴이라, 덱 접미 카드(`外資{系}`·`サービス{業}`)와 괄호 위치가 같음 → 예문·루비·k·g는 그대로. 바꿀 칸은 w·m·p·st(review.tsv에 다 적음). r은 `ウーマン` 그대로(checker가 r의 〜를 막음). sheet.json의 w도 같이 고쳐야 `--sheet` 검사를 통과함. キャリアウーマン으로 바꾸는 건 반대: 시트 항목이 아니고, 옛말·성별 색이 진한 말이 표제가 되며, e0(ビジネスウーマン)을 다시 써야 하고 다른 복합어를 못 덮음.
- **はしご 예문 3개 (21014)** → 3개 그대로 둠. 사다리(물건) · はしごする(가게를 옮겨 다니며 마심) · はしごを外される(업무 관용구: 도중에 뒷받침이 끊김)는 뜻이 확실히 다른 세 쓰임이고, 셋 다 m·p에 나옴 → CARD_SPEC §2의 3개 조건에 맞음. e0은 덱 틀 복사 아님(덱의 「〜ときは、必ず〜てください」는 鍵·安全靴뿐, 사다리 장면 없음. n2bn02 part의 命綱 문장은 덱에서 이미 바뀌었음).
- **일부러 남긴 경고** → 전부 맞음(고칠 것 없음).
  - 日本 にほん(ウーマン e0·温帯 e0), 月曜日 げつようび(重たい e1), 偶数 ぐうすう(偶数 e1), 応接間 おうせつま(応接 e0): 모두 표준 읽기. fugashi 쪽이 틀림.
  - 管理会社 かんりがいしゃ(水滴 e1): ○○会社 규칙대로 맞음. (이 예문은 1차 대조 때 n2cn06 〜滴 e1과 겹쳤지만 n2cn06 최종본에서 그 문장이 바뀌어 지금은 문제없음 — 그대로 둠.)
  - 私 わたし: ブローチ e0(가족 이야기)·温帯 e1(私たち)은 업무에서 자기를 낮추는 장면이 아님 → わたし가 맞음.
  - ピストル e1 「撃っ」: fugashi가 打つ로 잘못 봄. 풀이 `撃つ (총을) 쏘다`가 맞음.
  - 문맥 풀이 通る(「言い訳は…通りません」 → 받아들여지다·통하다), しまう(「乾かしてからしまいます」 → 넣어 두다·치우다, 덱에도 같은 문맥 풀이 있음), 外す(「はしごを外される」 → 떼다·빼다): 셋 다 문맥에 맞음. 通る의 괄호 '(의견이)'는 '(변명이)'가 더 정확하지만 오류는 아님.
  - ブローチ e0 g `てくる`(受け継がれてきました): 덱 표기와 같음, 경고 무시.
