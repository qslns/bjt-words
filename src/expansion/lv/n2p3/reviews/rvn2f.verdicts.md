# n2cn01 작성자 메모 판정 (rvn2f, 11/26)

- 准教授 m 「준교수(부교수급)」 — OK. 2007년 학교교육법 개정으로 助教授→准教授, 공식 영역은 associate professor, 한국 부교수에 해당. 시트 en 「assistant professor」가 틀렸고 고친 m·p·st가 맞음.
- 人文科学 = 인문학만 — OK. 대학의 3분류(人文・社会・自然科学)에서 人文科学는 문학·역사·철학, 사회과학은 社会科学(덱 20850). 사전에 '넓게는 사회과학 포함' 풀이도 있지만 p의 3분류 설명과 맞으니 m 「인문과학」 그대로.
- 〜校 c=gen — OK. 덱 〜館·〜史·〜園·〜科, 3부 〜問·〜畳가 모두 gen(〜社만 회사 말이라 org). y 「〜つの学校」도 덱 〜社 「〜つの会社」·〜問 「〜つの問題」와 같은 방식이라 그대로.
- 坊主 = 僧坊의 주인(坊の主) — 사실로 둬도 됨. 사전 풀이(본래 「房主/坊主」 = 僧房의 주인, 곧 住職 → 스님 일반) 그대로라 옛 풀이로는 불필요.
- コック(요리사) ← 네덜란드어 kok — 사실, OK(大辞泉 【(オランダ)kok】).
- コック(꼭지) ← 영어 cock — 사실, OK(大辞泉 【cock】, Wiktionary 語源2 English cock). st처럼 영어 cock으로만 적을 것. 꼭지 쪽을 네덜란드어 kok으로 적는 사전은 없음.
- 1920년대 시카고 갱의 술 밀매(e1) — 사실, OK(금주법 1920–1933, 카포네 등 시카고 조직이 밀주로 큰돈을 범).
- 노부나가의 대량 鉄砲(e0) — 사실, OK(長篠の戦い 1575, 信長公記 「鉄砲千挺ばかり」). 논란은 三段撃ち 쪽이고 예문은 그것을 말하지 않음.
- ほうき(ははき←羽掃き)·刺身(지느러미 꽂기)·蛇口(용머리 공용 수도) — 「옛 풀이로는」 처리 OK.
- 일부러 남긴 경고 13건 — 모두 OK(오경보). 300{校} 루비 없음 = 숫자 뒤 조수사 규칙(덱 3{社}와 같음) / ひっくり返す = 맞는 사전형(fugashi가 引っ繰り返す로 적을 뿐) / つく 「(팔꿈치를) 괴다·짚다」·かける 「(물을) 뿌리다·끼얹다」·よく 「잘·충분히」·ように 「~처럼」 = 문맥에 맞는 풀이 / 植木市 いち / 一晩中 ひとばんじゅう(경고 2건) / 座布団 ざぶとん(경고 2건, fugashi ざふとん이 틀림) / 鉄砲水 てっぽうみず / 曇ってきました의 てくる = 덱이 〜てきました를 늘 「(~てくる) ~해 오다·하고 오다」로 풀이(91회).
