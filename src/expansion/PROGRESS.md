### 잠금 규칙
1. 시작: `cd /home/claude/bjt-words && git fetch origin && git checkout expansion && git pull --rebase origin expansion` → 위 세 줄을 읽음. 시각은 `TZ=Asia/Seoul date '+%Y-%m-%d %H:%M'`.
2. 상태가 '작업중'이고 누가가 내가 아니고 마지막 신호가 **60분 안**이면:
   - 예약 작업(자동): 아무것도 바꾸지 말고 끝냄.
   - 페이지(사용자와 대화 중): 사용자에게 한 줄 알리고 넘겨받음(아래 3번으로 잠금을 페이지로 바꿔 push). 자동 쪽은 다음 push 전에 보고 멈춤.
3. 잠그기: 상태 `작업중`, 누가 `자동-MMDD-HHMM` 또는 `페이지-MMDD-HHMM`, 마지막 신호 = 지금 → 커밋 "잠금" → push. push가 밀리면 pull 뒤 1번부터.
4. 일하는 동안: 30분 안쪽마다(또는 작은 단위가 끝날 때마다) 커밋하면서 마지막 신호를 고침. push 직전 `git pull --rebase` → 누가가 남으로 바뀌었으면 지금 단위만 push하고 멈춤.
5. 끝낼 때: 아래 '다음 할 일'과 '작업 기록'을 고치고 상태 `없음` → push.
6. 2026-11-15 00:00 KST가 지나면 예약 작업은 일을 시작하지 않음(예약 작업 프롬프트에 끄는 방법이 있음).
