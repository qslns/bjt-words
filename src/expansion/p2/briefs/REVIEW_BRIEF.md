# 기본 추가 카드 검수 지시 (P2-4)

당신은 다른 사람이 쓴 BJT 단어장 '0부·기본' 카드를 검수하는 검수자예요. 작성자와 다른 사람이에요. **카드 파일을 고치지 말고** 오류를 TSV로만 적어요.

## 읽을 것
1. 사양 `/home/claude/work/expansion/CARD_SPEC.md` 전부(특히 7절 검수).
2. 검수할 카드: 아래 지정된 `/home/claude/bjt-words/src/expansion/p2/cards/p2wN.jsonl` (한 줄에 카드 하나) + 작성자 메모 `p2wN.notes.md`(작성자가 애매하다고 한 것 — 꼭 판정).
3. 참고: 작업 시트 `/home/claude/agents/p2wN/sheet.json`(한자 훈음 h 등), 지금 카드 `/home/claude/work/build/data_app.json`(기존 관례), 풀이 사전 `/home/claude/work/expansion/gloss_dict.json`.

## 볼 것 (진짜 오류만, 취향 말고)
- 틀리거나 비표준인 읽기 r, 예문 루비 j(方·何·中·後·日·人·上·間·会社=がいしゃ·明日=あす·私=わたくし, 숫자+조수사 읽기, 連濁).
- 틀리거나 오해를 부르는 뜻 m, 오역·어색한 번역 k.
- 부자연스러운 일본어 예문(비즈니스 장면에서 실제로 이렇게 말하나?), 경어 오류.
- 틀린 한국 한자음 ko, 지어낸 훈음, 사실처럼 단정한 어원 st(확실하지 않으면 '옛 풀이로는'으로 낮추거나 빼라고 제안).
- kr 나누기(熟字訓은 [] 또는 덩어리 — 지금 덱 관례: 一人·大人·今日 등은 [], 小売·最寄은 덩어리).
- 풀이 g: 빠진 내용어, 틀린 뜻, 문맥과 다른 뜻.
- p(BJT 포인트)의 틀린 정보, 성별 고정관념 장면, 같은 카드 두 예문이 같은 꼴, 다른 카드와 거의 같은 예문.
- 덱 관례: 한 글자 표제의 ko는 두음법칙 안 씀(来=래, 例=례). 茶는 단어마다 한국어 실제 음(お茶=차, 喫茶店=끽다점).

## 쓰는 꼴
`/home/claude/agents/<내 폴더>/review.tsv` — 한 줄에 하나, 탭으로:
`id	field	current	suggested	reason`
- field = r m p y o ko st kr c pr j0 j1 j2 k0 k1 k2 g0 g1 g2 (j0 = 예문 0의 루비 글 전체, g0 = 예문 0 풀이 전체를 JSON으로).
- suggested는 **그대로 바꿔 넣을 수 있는 완성 값**(j는 루비·{} 포함 전체 글, g·kr은 JSON 배열). 예문을 새로 지어야 하면 jN·kN·gN 세 줄을 함께.
- 오류 없는 카드는 안 적음. 끝 줄 `#SUMMARY 본 카드 n · 오류 n`.
- 작성자 메모의 애매한 것은 판정해서 고칠 거면 TSV에, 그대로면 `/home/claude/agents/<내 폴더>/verdicts.md`에 한 줄.

## 규칙
- 자기 폴더에만 씀. 다른 폴더·저장소는 읽기만, git 금지. 공식 모의 문제집 내용은 쓰지 않음.
- 바꿀 예문(jN)은 직접 지은 문장, 12~45자, 숫자 뒤 조수사 루비 없음.
- 마지막 보고는 짧게: 본 카드 수, 오류 수, 많이 나온 종류 3개.
