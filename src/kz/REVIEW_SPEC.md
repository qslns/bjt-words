## 점검표 (카드마다)
1. **장면 한 줄(hook)**: 읽자마자 그림이 떠오르는 한 장면인가, 장면 속 행동이 곧 뜻(앱 훈음/단어 뜻)인가, 괄호 속 부품이 실제 그 한자 모양 안에 있나, "~모습"으로 끝나나, 쉬운 말인가(추상어·소리 놀이·일본어 음차 금지), 너무 길지 않나(50자 안팎). 어둡거나 불쾌한 장면(죽음·폭력 과함, 성별 고정관념)은 부드럽게.
2. **그림 3칸**: p1 = 부품 그림, p2 = 부품별 색칠한 한자(색이 부품마다 다르고 tree 색과 맞나), p3 = hook 장면이 실제로 보이나. 잘림·겹쳐 가림·글자 넘침·너무 복잡해서 뭔지 모를 그림(항목 15개 넘게 직접 그린 것 등) 없나. 캡션 짧고 p3 끝 = "→ 앱 훈음".
3. **부수로 쪼개기(tree)**: 작은 것 → 중간 → 최종 순서, 각 부품이 실제로 그 모양인가(획 묶음 s: 포함 — 축소판에서 확인), 이름이 정식인가(`info`의 이름: / radicals.json, 같은 부품은 다른 카드와 같은 이름), 지어낸 가짜 훈음 없나(표준 훈음이 없으면 'X 모양'), mini가 그림처럼 구체적인가.
4. **소리 줄(snd)**: 읽기는 히라가나, 앱 읽기(음독·훈독)와 맞나, '한국음 X'가 앱 훈음의 음과 같나, 받침 규칙(ㄱ→く·き, ㄹ→つ·ち, ㄴ·ㅁ→ん, ㅇ→う·い, ㅂ→う, 첫소리 ㅎ→대개 か행)을 실제로 맞는 경우에만 썼나. 근거 없는 '규칙' 지어내기 금지.
5. **bridge·basic**: 뜻이 일본어 쓰임과 맞나, 사실과 다른 어원을 사실처럼 단정하지 않나(모양 연상은 괜찮지만 '원래 ~였다'고 틀리게 단정 금지).
6. 가타카나 0, 오타 0, 존댓말/반말 섞임 없이 샘플 말투.
