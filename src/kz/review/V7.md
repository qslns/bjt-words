# V7 검수 로그 (s14 s15 s16 s17)

방법: 배치마다 글 전부를 압축 덤프로 읽고(점검표 1~6) 축소판(--sheet)을 전부 확인함. 한국음 = 앱 훈음 끝 글자, 받침 규칙, snd 읽기 vs 앱 음독·훈독, 가타카나, 확장 한자, tree 이름의 이름표·다른 배치 카드와의 일치(전체 배치 교차 비교)를 스크립트로도 한 번 더 돌림. 고친 카드는 다시 렌더해서 다시 봄(僅·繁은 실제 크기로도). 수정 전 원본은 스크래치패드 rv_V7/orig 에 보관.

## 확인 못 한 것
- 실제 아이패드·윈도우·안드로이드의 이모지·글꼴 모양은 못 봄(헤드리스 렌더만 봄).
- 드문 조각의 읽기(歰 しゅう, 敫 けき)는 kzc hun 자료로만 맞춰 봤고 외부 사전은 못 봄. 睘·豦·歰·敫처럼 표준 훈음이 없는 조각은 'X 모양'이나 소리 이름(敫 '교')으로 되어 있음.
- 전체 배치 교차 비교에서 이름이 갈린 것은 僅의 堇뿐이었음(고침). 月 '달 월'/'육달월', 殳 '갖은등글월문'/'몽둥이 수'(중간 결과 이름)는 이름표가 허용하는 자리별 표기라 문제 아님.

## s14 (22장: 根 掛 廃 棄 操 財 還 省 滑 織 称 赴 背 簿 観 頂 戴 致 級 油 児 緩)
validate: 오류 0 · 주의 2 → 1 (織 해결 · 児는 이유가 있어 남김)

고친 카드
- 操 — tree 喿 이름 '버튼 달린 막대 모양'(중간 결과 '喿 …' 포함) → '입 셋 달린 나무 모양'. 같은 조각을 쓰는 繰(r11)는 이미 이 이름이라, 같은 부품이 카드마다 다르게 불리던 것을 맞춤.
- 織 — tree 戠 이름 '戠 (職·識의 부분)'은 이름이 아니라 설명이고 이름표와 달라 validate 주의 → 識(r11)와 같은 표준 훈음 '찰흙 시'로(중간 결과 '戠 찰흙 시'). '職·識의 부분'과 '소리(音)와 창(戈) 모양'은 note로 옮김.

고치지 않았지만 약한 카드
- 児 — validate 주의 하나를 일부러 남김(tree[0] '머리 모양' ≠ 이름표 '예 구'). 이 조각은 KanjiVG가 旧로 묶었을 뿐 '옛날'이 아니라 아기의 큰 머리 모양(児는 兒의 줄임꼴)이라, 이름표대로 '예 구'를 쓰면 오히려 헷갈림. note에 이미 "旧(예 구)처럼 생겼지만 여기선 아기의 큰 머리"라고 이유를 적어 둠.
- 致 — 막대로 화살을 툭 건드려 보내는 장면은 조금 억지. 부품이 다 나오고 뜻은 바로 보여서 둠.
- 棄 — 나무 밑에 쓰레기를 버리는 느낌이 어색하지만 부품과 뜻은 분명해서 둠.
- 級 — hook이 길고 p3 항목이 18개로 바쁘지만 축소판에서 또렷해서 둠.
- 滑 — '젖은 뼈'는 약간 이상하나 미끄러짐이 바로 보여서 둠.
- 称 — 벼에 이름 붙이기는 조금 이상하나 尓(너)와 '일컫다'가 보여서 둠.
- 還 — 睘은 표준 훈음이 없어 'X 모양'('눈·입·옷 모양')으로 쓴 조각. 이름은 정직하나 설명이 복잡한 편. 둠.
- 赴 — 卜의 note '소리 부분'은 KanjiVG를 따른 것인데 일본 읽기는 ぼく(卜)와 ふ(赴)로 달라 어색함. 학습에 해는 없다고 보고 둠.

플래그 처리
- 省 snd '성 ≠ 생' → 거짓 경보(앱 훈음이 둘이라 생긴 것).
- 頂 bridge '음차 의심' → 거짓 경보(한국 한자어 읽기일 뿐).
- 根·織·背·簿·戴·級·児 항목 수 많음 → 축소판에서 또렷해서 둠.

검수 완료: s14

## s15 (22장: 和 照 齢 縦 遽 網 羅 熟 繁 凡 創 脱 般 疎 即 功 酬 辞 紛 源 斉 到)
validate: 오류 0 · 주의 0 (처음부터 0, 고친 뒤도 0)

고친 카드
- 繁 — hook '엄마(毎)가 손(攵)을 쉴 새 없이 놀려 실(糸)을 짜서 …'는 엄마=실 짜는 사람이라는 성별 고정관념이고, 毎를 '엄마'로 부르는 것도 毎의 뜻(날마다)과 안 맞음 → '날마다(毎) 손(攵)을 쉴 새 없이 놀려 실(糸)을 짜니 …'. p1 캡션·그림(👩→📅), p2 캡션, p3 그림(👩→🧑, 📅 추가, 글자 자리 조정), tree[0] mini도 같이 고침. 실제 크기로 다시 확인함(R4의 繰 👩→🧑와 같은 유형).

고치지 않았지만 약한 카드
- 熟 — hook이 57자로 긴 편(60자 이내, 부품은 다 나옴).
- 齢 — 이 빠진 할아버지 그림이 조금 놀리는 느낌이나 불쾌할 정도는 아님.
- 凡 — 뜻이 추상적이라 그림이 약함.
- 疎 — 묶음을 발로 차 흩어지는 장면이 조금 거침.
- 即 — p3가 식탁 앞 얼굴이라 '다가앉는' 움직임이 약함.
- 紛 — 실을 자르면 엉킨다는 연결이 억지.
- 網·羅 — 직접 그린 그물이라 항목이 19~29개지만 또렷함.

플래그 처리
- 熟 hook 57자 → 60자 이내, 부품 다 나와서 둠.
- 網·羅·創·到 항목 수 많음 → 축소판에서 또렷해서 둠.

검수 완료: s15

## s16 (22장: 助 勧 躍 勘 系 歓 緯 懇 桁 渋 秀 副 禁 膨 互 己 激 層 埋 版 兼 充)
validate: 오류 0 · 주의 2 → 0 (躍·副 이름표)

고친 카드
- 躍 — tree 翟 이름 '꿩의 깃 적'(중간 결과 포함) → 이름표대로 '꿩 적'(曜 b06과 같음). '꿩의 깃 · 깃 달린 새'는 note로 옮김. validate 주의 해결.
- 副 — tree 畐 이름 '항아리 모양'(중간 결과 포함)은 표준 훈음이 있는 조각에 'X 모양'을 붙인 것 → 富(s13)·幅(r26)와 같은 '가득할 복'으로, '배부른 항아리 모양'은 note로 옮김. validate 주의 해결.
- 勧·歓 — tree 雚 이름 '황새 관' → '황새 관(줄인 꼴)'. 같은 조각을 쓰는 観(s14)이 '雚 황새 관(줄인 꼴)'이라 줄임꼴임이 이름에서 보이도록 맞춤(note에는 이미 '雚의 줄임꼴').

고치지 않았지만 약한 카드
- 副 — 칼로 항아리를 쪼개 나누는 장면은 억지스러움. 원래 뜻(나누다)과는 맞고 p3(큰 항아리·칼·작은 항아리)로 보여서 둠.
- 躍 — p3에 🤸와 🦶가 함께 나와 바쁜 편.
- 勘 — 사탕 무게 달기는 억지 연상.
- 渋 — 장면(막히다)과 앱 훈음(떫다)이 다름. 단어 渋滞 쪽 장면이고 bridge가 이어 줘서 둠.
- 兼 — 한 단계짜리 얕은 tree.
- 埋·版 — 동작이 여럿인 hook이지만 한 장면으로 이어져서 둠.
- 桁 — 자릿수와의 연결이 그림에 안 나옴.
- 歓 — '새 손님'의 새(鳥/新) 말놀이 소지가 있으나 (隹)와 '날아오자'로 새(鳥)임이 분명해서 둠.
- 激 — part 이름 '교(敫)'는 r10 宅·修의 소리만 쓴 이름('탁'·'유')과 표기 방식이 조금 다름(글자를 괄호로 덧붙임). 뜻은 같아서 건드리지 않음.

플래그 처리
- 緯·層 항목 수 많음 → 축소판에서 또렷해서 둠.

검수 완료: s16

## s17 (17장: 鑑 鎖 布 抗 身 挟 仮 揮 含 徒 駄 臨 礎 盤 僅 抱 徐)
validate: 오류 0 · 주의 0 (처음부터 0, 고친 뒤도 0)

고친 카드
- 僅 — 堇을 '메마른 땅 모양'·'堇 근'으로 풀고 hook도 '메마른 땅'이었는데, 같은 조각을 難(s02)·勤(b05)은 표준 훈음 '진흙 근'(진흙)으로 부르고 있어 카드끼리 부딪힘(진흙 vs 메마른 땅). 앞서 전체 배치 이름 교차 비교에서 잡음(s:범위 조각이라 검사기는 못 잡음). tree 이름을 '堇 진흙 근'·'진흙 근'(아래 조각은 '진흙땅 모양')으로 맞추고, hook '메마른 땅에' → '진흙땅에', p1·p2·p3 캡션·그림(마른 땅의 갈라진 금 → 진흙 덩이와 점), tree mini도 같이 고침. 실제 크기와 축소판으로 다시 확인함.

고치지 않았지만 약한 카드
- 鎖 — 직접 그린 사슬이 25개지만 또렷함.
- 身 — 항목 12개, 또렷함.
- 揮 — 항목 10개, 또렷함.
- 布 — ナ를 손으로 본 연상(MakeMeAHanzi 힌트와 같음).
- 礎 — 기둥 발이 돌 위에 서 있는 그림이 조금 복잡하나 뜻은 보임.
- 徒 — 부품 뜻 연결이 조금 억지.
- 駄 — 상자가 약간 떠 보임.

플래그 처리
- 鎖·身·揮 항목 수 많음 → 축소판에서 또렷해서 둠.

검수 완료: s17
