# R4 검수 로그 (r10 r11 r12 r13 r14)

## r10 (24장)
validate: 처음 오류 0 · 주의 2(適 啇 이름, 講 冓 이름) → 고친 뒤 오류 0 · 주의 0

### 고친 카드
- 適 — tree 啇 이름 '적' → 이름표대로 '밑동 적'(중간 결과·다음 단계 부품 둘 다)
- 講 — tree·p1 캡션 冓 이름 '어긋매겨 쌓을 구' → 이름표대로 '쌓을 구'(+note '나무를 어긋매겨 쌓은 모양')
- 追 — hook '언덕 위로 굴러가는 공'은 물리적으로 어색하고, p3에서 달리는 사람(🏃, 왼쪽을 봄)이 공 반대쪽으로 뛰는 그림이었음 → '언덕 아래로 데굴데굴 굴러가는 공을 헐레벌떡 쫓아가는 모습', p3를 내리막(사람 위·공 아래 왼쪽, 💨 추가)으로 다시 배치, 캡션·mini 맞춤

### 고치지 않았지만 약한 카드
- 並 — hook 괄호 (立)는 지금 모양에 온전히 보이진 않음(竝 두 立이 합쳐진 꼴). basic이 그 사실을 정확히 설명하므로 유지(자동 점검 '立 없음'은 이 이유로 무시).
- 検 — hook·캡션의 (僉)은 옛 모양이고 실제 오른쪽은 㑒(확장A라 글에 못 씀). 표준 분석이라 유지. 㑒 경보는 경로 키에만 있고 화면 글자로는 안 나옴(획으로 그림) → 거짓 경보.
- 倒 — p3가 사람을 20° 기울인 정도라 '넘어진' 느낌이 약함(💫·쿵!으로 보완). 이모지 회전 한도 때문에 유지.
- 謝 — hook 어순('말(言)로 몸(身)을 숙이고…')이 조금 어색하지만 뜻은 통함.
- 節 — snd 사슬이 진짜 소리 부분(即)이 아니라 卩(せつ)를 씀. 읽기 자체는 맞아서 유지.
- 거짓 경보 확인: 更 '경≠갱'(훈음이 둘), 商 '상' 음차 의심, 処 음차 의심, 適·講 그림 항목 수(벽돌·상자 도형이라 복잡하지 않음).

검수 완료: r10

## r11 (24장)
validate: 처음 오류 0 · 주의 2(録 ⺕ 이름, 識 戠 이름) → 고친 뒤 오류 0 · 주의 0

### 고친 카드
- 録 — tree ⺕ 이름 '손 모양' → 이름표대로 '돼지머리 계' + note '여기선 손 모양 · 부수 이름 튼가로왈'
- 識 — tree 戠 이름 '소리와 창 모양' → 이름표대로 '찰흙 시'(중간 결과 '戠 찰흙 시') + note '여기선 소리(音)와 창(戈) 모양'
- 繰 — p3 '수다 떠는 사람 셋'이 전부 👩(수다쟁이·실 감기 = 여자라는 고정관념) → 성별 없는 🧑로
- 了 — basic '실 끝을 매듭지은 모양을 그린 그림 글자예요'는 확인 안 되는 어원 단정(설문해자는 팔 없는 아이 모양) → '…모양으로 보면 쉬워요'
- 平 — basic '저울을 그린 그림 글자예요'도 정설 아님(물풀이 수면에 뜬 모양 등 여러 설) → '…저울 모양으로 보면 쉬워요'
- 従 — hook·p1·p2·mini의 '두 사람(八)': 실제 모양은 丷(뒤집힌 八)이라 괄호 삭제하고 말로만(tree에 '두 사람 모양' 획이 따로 보임). p3에서 🚶(왼쪽을 봄)이 오른쪽 발자국 반대로 걸어가던 그림 → 발자국·화살표를 왼쪽으로 옮겨 따라가는 방향과 맞춤

### 고치지 않았지만 약한 카드
- 績 — '꾸짖는 사장님 앞에 쌓인 실'은 '길쌈/실적'으로 이어지긴 하나 장면이 곧 뜻이라기엔 한 단계 돌아감(bridge가 보완). 積과 짝 구조라 외우기엔 도움.
- 縮 — p3의 '쪼그라든 스웨터'가 작은 🧥라서 '줄었다'가 그림만으로는 약함(글자 '앗, 줄었다!'로 보완).
- 恐 — '두 손(凡)'은 모양만으로는 손으로 안 보임(원래 丮=붙잡는 손이라 어원상은 맞음, tree note로 설명).
- 離 — 离의 표준 훈음은 '산신 리'(뜻과 무관)라 '그물 모양'으로 둔 것은 타당하다고 봄.
- 거짓 경보 확인: 各·積 그림 항목 수(같은 이모지 반복 배열이라 읽힘).

검수 완료: r11
