## k2b04 (27장)

축소판 p0~p6 전부 확인(27장). 刑·尾는 실제 크기로도 확인.

### 고친 카드
- 令 — tree 아랫부분(s:3-5 = 一 + マ) 이름 '무릎 꿇은 사람 모양' + note '원래 卩' → 기존 齢 카드와 같은 '꿇어앉은 사람 모양' + note '卩(병부 절)에 점이 붙은 모양'. 이 조각은 卩(マ)에 一 획이 붙은 것이라 '원래 卩'은 정확하지 않고, 같은 조각을 齢이 이미 이 이름으로 씀. 장면·p1 캡션(모양대로 '무릎 꿇은 사람')은 그대로. 다시 그려 확인.
- 刑 — p3 바닥에 놓인 칼 끝이 감옥 속 도둑 쪽을 향함(K2B '사람에게 겨눈 무기 금지') → 같은 자리에서 칼끝이 바깥(오른쪽)을 향하게 돌림(`knife` [60,92,0.8,90] → [90,92,0.8,-90]). 다시 그려 확인.
- 刑 — (k2b05 巻의 关 판정과 같은 기준으로) 글에 든 간체자 开를 뺌: hook '나무 틀(开) 감옥' → '나무 틀 감옥', p1 캡션 '틀 모양(开) + …' → '틀 모양 + …', mini '나무 틀(开)에' → '나무 틀에'. 开 조각은 표준 글자가 없어 말('나무 틀')로 부름. tree 이름·note(틀 모양 · 원래 幵)와 p1의 획 그림(K'开')은 그대로라 기존 型 카드와 이름은 같음. 다시 그려 확인.

### 작성자 의문 판정
- 傷 차 흠집: 유지. K2B 규칙상 다친 사람을 그릴 수 없고, 앱 단어 傷(きず)의 뜻이 '상처·흠집'이라 장면이 단어 뜻과 맞음. bridge가 상처·흠집·상하다로 이어 줌. 𠂉 '머리 장식[리본·비녀 모양]'은 기존 毎 카드와 같은 이름. 昜 '볕 양'·勿 '말 물[퍼지는 햇살]'은 기존 場·湯과 같음.
- 刑 만화 도둑+감옥: 장면 유지(칼 방향·开 글자만 고침). 开 '틀 모양[원래 幵 · 나무 틀처럼 생긴 모양]'은 기존 型 카드 안의 刑 단계와 글자 그대로 같음.
- 令/鈴 이름: 令 카드 쪼개기는 위처럼 齢에 맞춤. 鈴 안의 令은 '하여금 령'(+ note '명령할 령 · 命令의 令') 유지 — 令의 앱 훈음이자 이번에 새로 생기는 令 카드 이름이고, 최신 기존 카드 零과 같음. 기존 冷·命·領·齢의 '명령 령'은 표준 훈음이 아닌 옛 표기라 새 카드를 거기 맞추지 않음(그 4장은 내 범위 밖 — 보고에 남김).
- 筑 '비파 축': 유지. libhangul 훈 '비파 축'으로 도구 확인됨. 기존 카드에 筑 없음.
- 尾 🐿️: 유지. 어느 기기 그림이든 크고 복슬한 꼬리가 가장 눈에 띄고, 방향에 기대는 표시(화살표 등)가 없음.

### 고치지 않았지만 약한 카드
- (참고) 기존 앱 카드 型·研(开), 関·送·咲(关)는 아직 글에 간체자가 있음 — 내 범위 밖이라 그대로.
- 貨 — '짐 → 돈'은 화살표 하나가 있는 전/후 그림. 뜻(재화)은 바로 보여서 유지.
- 尾 p1 — 털(毛)을 🪶(깃털)로 보여 줌. 조금 어긋나지만 '복슬한 털'로 읽히고 p2·tree가 毛를 정식으로 보여 줘서 유지.

### 확인 사항
- 읽기: snd·bridge 읽기 전부 앱 음독·훈독에 있음(芝居 しばい의 い = 훈독 い(る), 執筆 しっぴつ 촉음 표시 등). 받침·ㅎ 규칙 21곳 전부 실제로 맞음(스크립트로 음절·읽기 대조: 執 집→しゅう ㅂ→う, 等 등→とう, 密 밀→みつ, 染 염→せん, 犯 범→はん 등). 老·著·居·尾·街는 규칙 말 없이 씀(맞는 처리).
- 이름 통일: 寺·者·耂·古·化·莫·昜·勿·𠂉·开·卩(병부 절)·尸·夫·干 모두 기존 카드와 같은 이름.
- 가타카나 0('・'는 읽기 구분점), hook 전부 '모습'으로 끝남, 캡션·mini 길이 초과 없음(스크립트 확인).

## k2b05 (27장)

validate: 처음 오류 0 · 주의 1(骨 '육달월' ≠ 이름표 '달 월') → 고친 뒤 오류 0 · 주의 0.
축소판 p0~p5 전부 확인(27장). 銃은 실제 크기로도 확인.

### 고친 카드
- 巻 — hook "두 손(关)으로…"의 关는 중국 간체자(글꼴 문제) → "두 손으로…"(괄호 없이 말로). 이 조각은 알맞은 표준 글자가 없어서(지침: 그런 조각은 말로) p1 캡션·tree 이름 '두 손 모양'과 맞춤. tree note(쌀을 두 손으로 뭉치는 모양 = 설문 '摶飯')는 정확해서 그대로. 다시 그려 확인.
- 銃 — p3가 🔫(왼쪽 과녁을 겨눔)의 방향에 기댐. 기기마다 🔫 방향이 달라 장면이 깨질 수 있음 → 칼(knife)처럼 직접 그린 장난감 물총(주황 몸통·파란 물통, 총구가 과녁 쪽)과 그린 물줄기·물방울로 바꿈(🎯·'쏴아!'·캡션은 그대로). 실제 크기로 다시 그려 확인 — 물총으로 바로 읽힘.
- 骨 — 아래 月은 원래 肉이라 '육달월'이 맞음(기존 有·育·腹·勝와 같은 이름·note). 이름표 주의만 없애려고 경로 `月` → `s:7-10`(같은 획, 기존 際·察·然·祭·湖·絹과 같은 방식), p2 색 키도 같이. 그림 변화 없음, 다시 그려 확인.
- 診 — p3 의사 말 '어디 아파?'가 hook의 '어디 아파요?'와 달라서 hook대로 '어디 아파요?'. 다시 그려 확인(넘침 없음).

### 작성자 의문 판정
- 骨 육달월: 위처럼 이름 유지 + 경로만 s:로.
- 巻 关: 위처럼 고침.
- 栄 '꽃(⺍)' → 컴파일 뒤 '꽃(小)': 유지. 컴파일러가 ⺍를 일부러 小로 바꾸고, 기존 労 카드가 똑같은 방식(hook '땀(小)' + tree '점 셋[勞의 火火를 줄인 모양]')이며 営·覚·堂도 hook에 (小)가 나옴. 栄만 다르게 하면 오히려 어긋남. tree note(榮의 火火를 줄인 모양)는 사실대로.
- 銃 🔫 방향: 위처럼 고침.
- 새 이모지 🪃(板 p1) 🪝(札) 🪙(銭·銃 p1) 🪜(挑 p1) 🫁(臓) 🥷(侵): 전부 13.0 이하, 축소판에서 뜻이 분명히 읽힘. 🫁는 분홍 폐 그림이라 징그럽지 않음, 🥷는 만화 같은 '살금살금 침입자'.

### 고치지 않았지만 약한 카드
- 挑 — '1조(兆) 칸 계단'은 숫자 뜻(조)을 끝없는 계단으로 바꾼 연상이라 조금 억지스럽지만 그림(계단+깃발+'도전!')은 바로 읽히고 앱 단어 挑戦과 맞음.
- 銭 — '창(戈)으로 쇠를 잘라 동전'은 모양 연상. 戔 쪼개기·이름은 기존 残 카드와 글자 그대로 같음.
- 銃 p1 — 充(채울 충)을 🎒+'가득'으로 보여 줌. 약하지만 틀리지 않아 유지.
- 骨 — hook·p1 캡션에 冎(드문 글자, 확장 한자는 아님)가 들어감. 이 조각을 가리킬 다른 글자가 없음.

### 확인 사항
- 읽기: 전부 앱 음독·훈독에 있음(仲間 なかま·仲良し なかよし·1巻 いっかん·看板 かんばん은 단어 읽기로 표시됨). 받침·ㅎ 규칙 16곳 전부 실제로 맞음(스크립트 대조: 籍 적→せき ㄱ→き, 札 찰→さつ, 恵 혜→けい ㅎ→か행, 宗 종→しゅう, 侵 침→しん ㅁ→ん 등). 秒 'ょう가 같아요'는 규칙이 아닌 관찰이라 허용.
- 枠(국자): p3 끝 '→ 틀', 마지막 res '틀'·r 없음, snd 훈독만 — K2B 규칙대로.
- 이름 통일: 戔(残)·歹(残·死)·육달월(有·育·腹·勝)·冎 '뼈 모양'·⺕ '돼지머리 계'·君·反·秀·蔵 기존 카드와 충돌 없음.
- 가타카나 0, hook 전부 '모습'으로 끝남, 길이 초과 없음.

## k2b06 (27장)

validate: 처음 오류 0 · 주의 0 → 고친 뒤에도 오류 0 · 주의 0.
축소판 p0~p5 전부 확인(27장). 微는 실제 크기로도 확인.

### 고친 카드
- 郷 — hook·p1 캡션·mini에 간체자 乡(巻의 关와 같은 글꼴 문제)이 들어감 → hook '돌아온 사람(乡)이' → '돌아와 앉은 사람이', p1 캡션 '사람(乡) + …' → '앉은 사람 + …'(p2 캡션·tree 이름 '앉은 사람 모양'과 같게), mini 끝 '앉은 사람(乡)' → '앉은 사람'. 다시 그려 확인.
- 柱 — snd '注·駐처럼 오른쪽에 主가 붙으면 ちゅう'는 사실이 아닌 일반 규칙(住는 じゅう, 往는 おう — 둘 다 기본 한자) → '注(부을 주)·駐(머무를 주)도 ちゅう → 柱도 ちゅう'로 사슬만 남김. 다시 그려 확인.

### 작성자 의문 판정
- 症 '正 = 똑바로 누운': 유지. 正(바를 정)의 뜻 '바르다/똑바로'에서 나온 모양 연상이라 틀리지 않고, 장면의 뜻(열·기침 증세 = 症状)은 🤒·🌡️·'열·콜록'으로 바로 보임. 약한 연결이라는 점은 인정(아래).
- 微 작은 사람: 유지. 실제 크기 칸(약 200px)에서 사람이 칸의 11%(아이패드 레티나에서 충분히 또렷)이고 빨간 동그라미 + '요만해!'가 짚어 줌. '아주 작다'가 장면의 요점이라 키우면 뜻이 약해짐. s:4-9(山 + 兀)를 '메 산'으로 묶은 건 note에 兀을 밝혀 둬서 정직함(나누면 한 단계 부품이 4개).
- 純 屯 = 목화 새싹: 유지. 屯은 설문해자에서 '풀이 땅을 뚫고 처음 나오는 모양'이라 '새싹 모양'은 근거 있음('목화'는 실과 잇는 연상). 이름 '진칠 둔'은 libhangul과 같음.
- 綱 綱引き: 유지. bridge에 '綱引き つなひき 줄다리기'로 단어·읽기·뜻을 함께 적어 단어 예시임이 분명함.
- 廌 '해태 치': 유지. libhangul엔 음(치)만 있지만 한국 한자사전 관례 훈이 '해태 치(채)'이고 廌 자체가 해태(獬豸)를 그린 글자. 기존 懇 카드도 '해태 치'라는 이름을 씀(그쪽은 豸 조각).

### 고치지 않았지만 약한 카드
- 症 — 正 → '똑바로 누운'은 모양·뜻 연상이 약함. 더 나은 구체 장면을 못 찾음.
- 純 — '새싹에서 실을 뽑는다'는 실제와 다른 연상(사실 단정은 아님).
- 薦 — 廌(해태)가 학습자에게 낯선 조각. 🦁에 뿔을 그려 넣어 해태로 보이게 한 건 잘됨.
- 華 — 아래 조각을 '드리울 수(垂가 조금 변한 모양)'로 부름. KanjiVG 표시(垂 변형)를 따른 것이고 장면과는 잘 맞음.

### 확인 사항
- 이름 통일: 昜·旦·勿(場·湯), 夬 '결단할 쾌[큰 대(大)에 막대 하나]'(決), 主 = 점 주[불꽃] + 구슬옥변[등잔대 모양](住와 글자 그대로 같음), 釆 '분별할 변', 岡 '산등성이 강', 兀 '우뚝할 올' — libhangul·기존 카드와 맞음.
- 읽기: 전부 앱 음독·훈독에 있음(芝·杉은 음독 없음 → snd 훈독만, 마지막 res r 없음). 綱引き·華やか·毛皮 けがわ·妙な 등은 단어 읽기로 표시됨. 받침·ㅎ 규칙 15곳 전부 실제로 맞음(스크립트 대조).
- 앱 훈음과 다른 일본어 뜻을 따른 장면: 芝(지초 → 잔디), 綱(벼리 → 밧줄), 奏(아뢸 → 연주), 哲(밝을 → 철학) — 모두 bridge가 이어 줌.
- 가타카나 0, hook 전부 '모습'으로 끝남, 길이 초과 없음.
