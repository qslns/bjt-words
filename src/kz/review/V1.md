# V1 검수 로그 (b06 b07 b08 b09 b10 r02)

총 76장 (b06 10 · b07 10 · b08 5 · b09 12 · b10 15 · r02 24). 배치 파일을 통째로 읽고 카드마다 점검표대로 확인했고, 축소판(--sheet)은 모든 페이지를 열어 봤다. 앞서 일부 검수가 있었던 배치도 전 카드를 새로 봤다. 고친 4장은 고친 뒤 validate와 축소판을 다시 돌려 그 카드를 다시 봤다(아래 '고친 카드' 참고).

## 확인 못 한 것 · 남은 걱정 (공통)
- 아이패드 실제 화면 렌더링은 이 환경에서 확인하지 못함. 이모지 중 비교적 새 것(🛕 12.0, 🤱 12.0, 🪢 🪚 🪵 🪨 🪣 🪶 13.0)이 오래된 iOS에서는 네모로 보일 수 있음(지침 상한 13.1 이내라 통과시킴).
- ⺍→小 같은 RADFIX 치환(営·労 등)은 도구 설계대로 동작하는지만 보고, 아이패드 글꼴에서의 모양은 확인하지 못함.
- 약한 연상 카드(毎 存 承 職 待 予 次 解 常 調)는 사실 단정이 없어 그대로 뒀지만, 복습할 때 연상이 안 떠오르는 학습자가 있을 수 있음.
- 待의 🛕는 힌두 사원 그림. '절/사원' 뜻은 전달되지만 불교 사찰은 아님.

고친 카드
- (없음)

고치지 않았지만 약한 카드
- 予 — 'マ' 모양을 미끼로 보는 연상이라 모양 근거는 약함. bridge가 予定·予約로 '미리' 뜻을 이어 주고 장면(고기 오기 전 미끼)이 뜻과 맞아서 둠.

## b09 (12장: 増 済 差 承 比 具 結 払 学 寄 存 常)
validate: 오류 0 · 주의 0 (처음부터 끝까지 0)

고친 카드
- (없음)

고치지 않았지만 약한 카드
- 存 — '지붕(一)·사람(亻)'은 원래 才 모양을 느슨하게 읽은 연상. tree note에 "一+亻은 원래 才(재주 재)"라고 정직하게 적혀 있고 '아이를 품고 있다'가 뜻(있을 존)과 이어져서 둠.
- 承 — '바통'은 장면용 비유일 뿐 어원 단정은 아님. 구조(手 + 두 손 廾)는 정확해서 둠.
- 常 — 尚을 '집'으로 보는 건 억지지만 깃발(巾)이 또렷하고 '늘 당당히'로 뜻이 보여서 둠.

플래그 처리
- 増·差 p3 항목 11개(복잡) → 축소판에서 장면이 또렷해서 둠.
- 承 hook '廾가 부품 목록에 없음' → 거짓 경보(KanjiVG가 廾를 이름 없는 획 묶음 s:6-8로 둬서 목록에 안 잡힘. 확대해서 s:1-5=手 모양, s:6-8=양옆 두 손(廾) 모양임을 확인).
- 存 hook '一가 부품 목록에 없음' → 거짓 경보(1획 가로획 s:1이 실제로 있음).
- 常 bridge·snd '음차 의심' → 거짓 경보('항상·정상·한국음 상'의 '상').

검수 완료: b09

## b10 (15장: 延 保 満 能 接 労 解 材 電 番 必 考 聞 題 参)
validate: 오류 0 · 주의 1 → 0 (題 이름표)

고친 카드
- 題 — tree 1단계 疋 이름 '짝 필'이 이름표('발 소')와 달라 validate '주의'. 이름을 '발 소'로, note를 '발 모양 · 짝 필이라고도 해요'로 바꿈(주의 해결).
- 必 — 丿(오른쪽 위에서 왼쪽 아래로 삐치는 획)인데 p1의 빨간 선과 p3의 어깨띠가 반대 방향(＼)으로 그려져 글자 모양과 어긋남. p1 선 [64,30,84,74] → [84,30,64,74], p3 띠 [43,42,57,64] → [57,42,43,64]로 뒤집음(／ 방향). 축소판에서 다시 확인함.

고치지 않았지만 약한 카드
- 解 — 소 뿔에 묶인 줄은 글자에 없는 장면용 소품(실제 글자는 칼·소·뿔). 어원을 '원래 ~였다'고 단정하지 않고 '풀 해' 뜻을 장면으로 보여 주는 연상이라 둠.
- 能 — 중간 조각 䏍를 '곰 머리·몸'이라 부름(표준 이름이 없는 조각이지만 KanjiVG 묶음 그대로이고 이름이 정직해서 둠. 後·向과 같은 처리).

플래그 처리
- 能 '확장A 글자 䏍' → 거짓 경보(䏍는 p2 색칠 키와 tree의 경로 `p` 안에만 있고, 화면에 보이는 글(hook·캡션·이름·note·mini)에는 없음. 내 6개 배치 전체에서 화면 글에 확장A 글자가 나오는 카드 0장).
- 電 hook '申가 부품 목록에 없음' → 거짓 경보(KanjiVG가 s:9-13 묶음으로 둠. tree note에 '申이 바뀐 모양'이라고 적혀 있고 축소판에서 번개 모양 확인).
- 番 p3 항목 12개(복잡) → 축소판에서 네 칸 밭·1~4 번호·씨앗이 또렷해서 둠.

검수 완료: b10

## r02 (24장: 店 生 明 経 意 返 回 動 名 力 産 点 全 代 以 利 持 週 交 伝 変 礼 計 原)
validate: 오류 0 · 주의 0 (처음부터 끝까지 0)

고친 카드
- 店 — tree 2단계 mini가 '입(占)으로'라고 써서 占(점칠 점)을 '입'이라 부름. '집(广)에서 팻말(卜) 걸고 입(口)으로 손님을 불러 장사해요'로 고침(hook·p2 캡션과 같은 부품 이름으로 맞춤).
- 全 — 위쪽을 사람(人)으로 설명했는데 정식 분석은 入(들 입) + 玉(MakeMeAHanzi ⿱入玉, 앱의 옛 해설도 入 + 王<玉>)이라 부품 이름이 틀림(KanjiVG 라벨만 人). hook을 '구슬(玉)을 주머니에 쏙 넣어(入) ‘안 깨졌네, 온전해!’ 하는 모습'으로 새로 쓰고 p1(入 모양 + 구슬)·p2 색(s:1-2 파랑 / 王 주황)·p2 캡션·p3(구슬 → 쏙! → 주머니, ✅ 온전해!)·tree(들 입 + 구슬옥변)·mini를 모두 새 장면에 맞춰 고침. p3 캡션은 '→ 온전할 전'(앱 훈음)으로 끝남. validate 오류 0·주의 0, 자동 플래그 0, 축소판에서 다시 확인함.

고치지 않았지만 약한 카드
- 力 — basic 글의 '알통 솟은 팔을 그린 그림 글자예요'는 설문해자(象人筋之形)에 따른 전통 설명이지만 쟁기 모양이라는 학설도 있음. 한국 교재 통설이고 큰 오해를 낳지 않아 둠(남은 걱정).

플래그 처리
- 以 bridge '음차 의심' → 거짓 경보('이상'의 '상').
- 持 p1 항목 11개(복잡) → 손그림 절이 축소판에서 지붕·기둥이 또렷해서 둠.
- 週 p3 항목 11개(복잡) → 일곱 칸 달력과 걷는 사람이 또렷해서 둠.

검수 완료: r02
