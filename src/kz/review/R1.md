# R1 검수 로그 (b01~b10)

## b01 (10장: 上出手社入見一会合下)
- validate: 오류 0, 주의 0. flags: 上 snd '…상'·下 basic '…상' = 거짓 경보(음차 아님).
- 고친 카드:
  - 一 — p1 🪵 이모지가 축소판(Noto)에서 세워진 그루터기로 나와 캡션·hook '가로로 누운 통나무'와 어긋남 → 기기 무관하게 가로 통나무를 도형으로 직접 그림.
- 약하지만 둠: 없음.
검수 완료: b01

## b02 (10장: 場気当発品引間部分不)
- validate: 오류 0. 주의 1(当 튼가로왈) → 고침. flags: 分 p3 10항목 = 사과 반쪽 그림이라 또렷함(문제없음). 不 snd '불·부' = 不은 실제로 불·부 두 음이고 예(不満 불만·不足 부족)를 붙여 둬서 그대로 둠.
- 고친 카드:
  - 当 — tree 이름 '튼가로왈' → 이름표대로 '돼지머리 계' + note '여기선 손 모양 · 부수 이름 튼가로왈', p1 캡션도 같은 이름으로.
- 약하지만 둠: 発 — 앱 훈음은 '필 발'인데 장면은 '출발'(일본어 쓰임 発送·出発 쪽이라 지침상 허용).
검수 완료: b02

## b03 (10장: 書金長方内最切目足配)
- validate: 오류 0. 주의 2(書·最 '날 일') → 고침. flags: 切 p3 10항목 = 끈 토막 7개라 단순(문제없음).
- 고친 카드:
  - 書 — tree 日 이름 '날 일' → 이름표대로 '가로 왈'(원래 曰) + note '여기선 해(日) 모양', p1 캡션도 '가로 왈(曰)'로. hook의 '오늘(日)'은 모양대로 부른 것이라 둠.
  - 最 — tree 日 이름 '날 일' → '가로 왈' + note '여기선 해(日) 모양'.
- 약하지만 둠: 없음.
검수 완료: b03

## b04 (20장: 員理外物同務中新要高自別付関決込機違実議)
- validate: 오류 0. 주의 1(理 '임금 왕') → 고침. flags: 違 p3 10항목(길 차선 점선), 実 p3 12항목(사과 9개 격자) = 그림은 또렷해서 둠.
- 고친 카드:
  - 理 — tree 王 이름 '임금 왕' → '구슬옥변' + note '원래 玉(구슬 옥) · 모양은 王', p1 캡션도 '구슬옥변(王)'. hook의 '왕(王)'은 모양대로 부른 것이라 둠.
  - 関 — 关에 지어낸 훈음 '빗장 관'(+읽기 かん)을 씀 → '빗장 모양' + note '옛 글자 關 속 빗장을 줄인 꼴', 가짜 읽기 r 삭제. p1 캡션도 '빗장 모양(关)'.
  - 込 — 음독 없는 한자인데 마지막 결과 r에 'こむ'(훈독)를 넣음 → r 삭제(지침: 음독 없으면 r 생략). snd에 훈독 こ(む)·こ(める)가 이미 있음.
- 약하지만 둠: 要 — '꼭 필요한 것만 담은 바구니' 장면은 그림만으론 '필요'가 약하고 말로 받쳐짐(대안인 허리 어원은 bridge가 더 필요해 그대로). 員 — '월급 받을 입이 몇?'(식구=입) 연결이 살짝 돌아감. 議 — 1단계 mini 끝 '· 소리 ぎ'는 r과 겹치는 군말(해는 없음).
검수 완료: b04

## b05 (15장: 集知重割面進無口開勤運記費数様)
- validate: 오류 0, 주의 0. flags: 面 '目 부품 없음' = 面 안쪽 눈 모양(획 5~8)이 실제로 있어 거짓 경보. 開 '一·廾 부품 없음' = 开를 한 일(획 9)+받들 공(획 10~12)으로 나눈 것이고 실제 어원(두 손으로 빗장을 듦)과도 맞아 거짓 경보. 数 p3 10항목 = 쌀알 1·2·3 그림이라 또렷함.
- 고친 카드: 없음.
- 약하지만 둠: 無 — 灬은 어원상 불이 아니지만(춤추는 사람 발) 모양 연상으로만 썼고 '원래 불'이라 단정하지 않아 허용. 開·無·運·費 p1 캡션이 정식 이름 대신 장면 말(빗장·장작더미·덮개·달러)을 섞음 — 뜻은 통해서 둠.
검수 완료: b05
