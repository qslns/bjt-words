방법: 세 배치를 rk2a/ 로 복사한 뒤 카드마다 `kzc.py info`와 대조해 글 전체를 읽음. 축소판 20장(pv/k2a01_p0~5, k2a02_p0~6, k2a03_p0~6)을 모두 봄. 의심 칸은 잘라서 확대해 봄(民 p2, 米 p3, 村 p3, 官 p3). 부품 이름은 `kzc.py hun`과 앱의 기존 950장(kz_cards.json)의 같은 부품 이름과 맞춰 봄(歹·戈 틀·龶·甫·也·侖·莫·聿·祭·及·次·弋·舎·彔 등). snd 규칙 문구와 쓰인 가나도 모두 앱 읽기와 맞춰 봄.
validate: 처음부터 세 배치 모두 오류 0 · 주의 0. 고친 뒤에도 오류 0 · 주의 0. 고친 카드 2장은 축소판을 새로 만들어 다시 봄.

## 고친 카드
- 蔵 (k2a01) — tree 틀 부품(s:4-5,13-15) 이름: '창 과' + note '왼쪽 삐침이 하나 더 붙은 꼴' → '창 모양' + note '안에 **戈**(창 과)가 있어요'. 그 획 묶음은 戈가 아니고 戈+丿(戊 꼴)이라서, 戈의 정식 훈음을 그대로 붙이면 다른 부품에 이름을 붙이는 셈임. 戈가 들어 있는 틀을 다룬 기존 歳 카드와 같은 처리로 맞춤. hook과 p1의 '창(戈)'은 그 안에 실제로 戈가 있어서 그대로 둠.
- 悲 (k2a03) — p1 캡션: '두 쪽 아닐 비(非) + 마음 심(心)' → '아닐 비(非) + 마음 심(心)'. 앞의 글은 '두 쪽이 아니다'로 잘못 읽힐 수 있음. '두 쪽'이라는 생각은 p1 그림(非를 두 색으로 칠함)과 p2 캡션이 이미 보여 줌.

## 작성자 의문 판정 (한 줄씩)
### k2a01
- 丸 hook이 모양 그림뿐(九=미끄럼틀, 丶=구슬): 유지. 동그란 구슬이 데굴데굴 굴러 '둥글다'가 장면에 바로 보이고, 모양으로 떠올리는 연상은 KANJI_SPEC이 허용함. p3에서도 구슬이 굴러 내려오는 게 보임.
- 民이 百姓에 기댐: 유지. 百姓(백 가지 성 → 백성)은 실제 낱말 뜻이라 지어낸 어원이 아니고, 民의 어원이라고 단정하지도 않음. s:1 '지붕 모양'도 맨 위 ㄱ자 덮개로 보임(확대 확인).
- 科 장면은 '나눠 담기', 과목은 bridge가 이음: 유지(아래 '약한 카드'에 올림). 벼를 칸칸이 나누는 장면은 구체적이고, bridge '종류별로 나눈 갈래 → 과목'이 바로 이어 줌. '과목'을 한 장면으로 보여 줄 더 나은 안은 찾지 못함.
- 田 snd에 田舎 いなか: 유지. '田舎는 통째로 いなか'라서 낱말 읽기임이 분명함(K2_REVIEW_NOTE 조건 충족).
- 青이 龶를 새싹(生)이라 부름: 유지. tree 이름 '날 생 모양'과 note '生에서 맨 위 삐침이 빠진 꼴'이 정확하고, 기존 精 카드의 龶 이름과 같음.
- 蔵 틀 부품을 '창 과' + note로 씀: 고침(위 참고).
- 이모지 🛖 🪦 🧑‍💼 🧑‍🏫: 유지. 각각 Emoji 13.0 · 13.0 · 12.1 · 12.1이라 13.1 이하(검사기 통과). 축소판에서 오두막 · 비석 · 회사원 · 선생님으로 제대로 보임.
- 米 쌀알 대비가 낮음: 유지. 확대해 보니 흰 타원과 갈색 테두리가 크림색 바탕에서 또렷함.

### k2a02
- 散 hook의 (艹)가 정확히 艹는 아닌 조각: 유지. 그 조각은 艹에 가로획 하나를 더한 꼴이라 艹 모양이 실제로 들어 있음. tree는 '풀 모양' + note로 정직하게 씀.
- 走 hook의 발(止)이 변형 모양: 유지. 아래 부품(龰)은 아래에 올 때 바뀐 止이고, tree가 '발 모양 · 원래 止'로 설명함. 드문 글자 龰을 글에 쓰지 않은 것도 규칙에 맞음.
- 森 snd 삼→しん: 유지. 내세운 규칙은 '받침 ㅁ은 ん'뿐이고 그건 맞음. 모음은 규칙이라고 하지 않음.
- 星 '아기 해들'이 엉뚱함: 유지. 한 장면으로 그려지고, bridge '별은 멀리 있는 해예요'는 사실임.
- 이모지 방향·기기 차이(坂 🧗, 船 👨‍👩‍👧‍👦 둘, 彼 🚶): 유지. 🧗은 '오르는' 동작이라 방향이 상관없음. 👨‍👩‍👧‍👦는 Emoji 2.0 ZWJ 묶음이라 아이패드·안드로이드에서 한 그림으로 나옴. 彼는 늘 오른쪽을 가리키는 👉가 사람을 가리키는 구도라 🚶가 어느 쪽을 보든 상관없음.
- 夭를 '어여쁠 요'로 부름: 유지. libhangul의 첫 훈음이고, '일찍 죽을 요'를 피한 좋은 선택.

### k2a03
- 尭를 '높을 요'로 부름: 유지. 堯의 표준 훈음(높을 요 · 요임금 요)이고, note가 줄인 모양임을 밝힘.
- 塩의 𠂉를 監의 人에서 온 조각으로 봄: 유지. 실제로 그러함(鹽의 監 → 塩의 𠂉+口+皿). 이름 '사람 모양'과 중간 이름 'X 모양'도 정직함. 기존 覧·臨 카드도 같은 조각을 '숙인 몸 모양' 식으로 부름.
- 薄이 甫를 '잔'으로 보고 🍵를 40% 투명으로 그림: 유지. 모양 연상이고 mini가 설명함. 흐린 찻잔이 '연한 차'를 보여 주고, 축소판에서 잔이 또렷이 알아보여 꺼진 아이콘처럼 보이지 않음.
- 吸 p3 🥤와 袋 p3 🚶가 기기 모양에 달림: 유지. 吸는 얼굴이 컵 바로 위라 빨대 각도가 달라도 '빨아 마시기'로 보임. 袋는 🚶가 대부분 기기에서 왼쪽을 봐서 막대가 어깨 뒤로 가는 보따리 모양이 되고, 반대쪽을 봐도 막대에 매단 자루로 읽힘.
- 舎 snd의 田舎 いなか: 유지. '두 글자를 통째로 읽는 특별한 읽기예요'로 분명히 표시함.

## 고치지 않았지만 약하다고 보는 카드
- 科 (k2a01): 장면이 보여 주는 것은 '등급별로 나눠 담기'이고 '과목'은 bridge를 거쳐야 이어짐. hook만으로 뜻을 맞히기는 어려움.
- 官 (k2a01): hook에는 '도장을 쾅'이 있는데 p3에는 도장이 없음(지붕 + 관리 + 서류 더미 + '쾅!'). 뜻(나랏일 하는 관리)은 보여서 둠. 도장 이모지가 없고, 그려 넣으면 📚의 빨간 표지와 겹쳐 안 보임.
- 坂 (k2a02): Noto의 🧗에는 바위벽이 붙어 나와서 비탈 그림 안에 벽이 하나 더 보임. 오르는 장면은 읽혀서 둠.
- 散 (k2a02): p3 항목이 16개(그린 원 10개)라 반딧불이가 별처럼 보일 수 있음. 캡션이 받쳐 줌.
- 輪 (k2a02): p3에 직접 그린 항목이 16개지만 바퀴 둘 달린 수레로 또렷해서 둠.

## 확인 못 한 것
- 이모지는 미리보기 글꼴(Noto)로만 봄. 실제 아이패드·윈도에서의 모양(🥤 빨대 방향, 💪 방향, 🧗 바위벽, 👨‍👩‍👧‍👦 합쳐짐)은 확인 못 함.
