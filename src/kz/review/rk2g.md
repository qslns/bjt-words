## k2c01 (27장) — validate: 오류 0, 주의 0
고친 카드
- 鹿 — bridge를 "→ 馬鹿(ばか) 바보: 소리만 빌린 한자 · ‘말(馬)과 사슴(鹿)도 못 가리는 사람’으로 기억"으로 고침: 기억용 연상이 진짜 어원처럼 읽히지 않게, 馬鹿가 소리만 빌린 표기임을 밝힘.
- 誘 — hook · p3 캡션 · p3 그림 글자 · mini의 ‘이리 와!’를 ‘같이 먹자!’로 고침: 장면이 먹이로 꾀어내는 것에서 앱 단어 誘う(권하다·초대하다)의 '같이 하자고 권함'으로 바뀜. 캡션 끝 "→ 꾈 유"는 그대로이고, 축소판에서 다시 확인함.
- 縄 — tree note "원래 黽(맹꽁이 민)을 줄인 모양"을 "원래 黽(맹꽁이)를 줄인 모양"으로 고침: 黽 훈음은 자료마다 다름(libhangul '맹꽁이 민', 나무위키 '힘쓸 민, 맹꽁이 맹'). 그래서 어느 쪽에도 틀리지 않게 음을 뺌. 이름 '맹꽁이 모양'은 그대로(앱에 黽·亀 카드 없음).
작성자 의문 결정
- 辟 '임금 벽' — 그대로. 앱의 壁 카드가 같은 부품을 '辟 임금 벽'으로 씀. '피할 피'로 하면 tree가 "피할 피 + 책받침 = 피할 피"로 같은 말을 되풀이함.
- 鹿 bridge — 위처럼 고침.
- 京 snd의 東京 — 그대로. 단어 읽기로 분명히 표시됨(とう**きょう**), きょう는 앱 읽기, 東京은 사용자가 가장 잘 아는 단어.
- 誘 장면 — 위처럼 고침.
- 縄 '맹꽁이 모양' — 이름은 그대로. 电(중국 간체 '번개 전')을 이름으로 쓰면 오해를 부름. 줄어든 꼴이라 'X 모양' + note로 둠. note만 위처럼 고침.
- 譲 · 縄 · 徳 hook의 襄 · 黽 · 直 — 그대로. 실제 줄어든 꼴은 㐮(확장 A), 电(오해), 十+罒(해당 글자 없음)라 글에 쓸 수 없음. 앱의 嬢 카드도 같은 부품을 hook에 '드레스(襄)'로 씀. tree note가 '줄인 모양'임을 밝힘.
고치지 않았지만 약한 카드
- 荒 — hook에는 '냇물도 말라 사라진 땅'이 있지만 p3엔 낡은 집 + 잡초 + 갈라진 땅만 있고 마른 냇물은 안 보임. 그래도 '황폐'는 분명히 보여서 둠.
- 稲 — 장면의 행동은 '찧기'이고 뜻 '벼'는 그 대상. hook에 벼(禾)가 바로 나와 뜻은 맞힐 수 있어서 둠.

## k2c02 (26장) — validate: 오류 0, 주의 1 (狂 — 아래 이유로 해소)
고친 카드: 없음
작성자 의문 결정
- 叫 丩 '얽힐 구' — 그대로. 사전 훈음임(나무위키 '얽힐 구/교'). 소리 구 → 규 힌트도 됨. 단, 앱의 収 카드는 같은 부품을 '갈고리 막대 모양'으로 씀 → 이름이 서로 안 맞음. 収 쪽을 '얽힐 구'(note '여기선 갈고리 막대 모양')로 맞추길 권함(내 배치 밖이라 못 고침).
- 斎 斉=さい 사슬 — 그대로. さい는 斉의 실제 읽기이고, 앱의 済 카드가 같은 사슬('斉 = さい → 済도 さい')을 씀.
- 鋭 兌=えい 사슬 — 그대로. えい는 兌의 실제 읽기. 兌는 앱의 説·税·脱·閲 tree에 '바꿀 태'로 이미 나오고, 閲(えつ)·脱(だ)도 兌 사슬을 씀. '한국음 예 → えい'도 함께 있음.
- 罰 장면이 복잡함(49자) — 그대로. 60자 이하이고 세 부품이 모두 구체적임. 벌은 치즈 반 토막으로 가볍고 생쥐는 다치지 않으며, p3에서 장면이 읽힘.
- 狂 王 '임금 왕'(validate 주의) — 그대로. KanjiVG가 이 王을 玉으로 잘못 표시한 것. 狂 = 犭 + 王(소리 왕 → 광)이고 MakeMeAHanzi도 소리 부분을 王으로 봄. note "소리 부분 · 여기선 진짜 임금 王"이 이유를 밝힘.
- 黙 黒을 깜깜한 밤으로 — 그대로. 검다 → 깜깜한 밤은 자연스럽고 p3가 분명함.
고치지 않았지만 약한 카드: 없음
검수 완료: k2c02

## k2c03 (26장) — validate: 오류 0, 주의 0
고친 카드
- 麦 — hook · p1 캡션 · mini에서 '(龶)'를 뺌: 龶(U+9FB6)는 드문 부품 글자라 KANJI_SPEC의 "그런 조각은 말로" 규칙을 따름. tree 칸과 p2는 획 그림이라 그 모양은 그대로 보임. 축소판에서 다시 확인함.
작성자 의문 결정
- 潔 絜 '깨끗할 결' — 그대로. 絜은 潔의 옛 글자이고 사전 훈음이 '잴 혈, 깨끗할 결'(나무위키). 소리 사슬 けつ → けつ도 맞음.
- 麦 龶 — 위처럼 뺌. 참고: 앱의 素 카드는 hook · 캡션 · mini에 龶를 그대로 씀. GB18030 부품 글자라 PingFang · YaHei · Noto CJK에는 들어 있어 아마 보이겠지만, 사용자 아이패드에서 한 번 확인 권함.
- 劣 🏃 flip — 그대로. 주요 기기(애플·구글·MS·삼성)가 모두 🏃를 왼쪽 보는 모습으로 그려서(그래서 Emoji 15.1에 오른쪽 보는 변형이 따로 생김) flip하면 늘 결승선 쪽을 봄. 뒤처진 것은 위치 · '헉헉' · 💦로도 보임.
- 屈 🙇 — 그대로. 훈음이 '굽힐'이라 몸을 굽힌 🙇가 맞음. '심심해~'와 ⚽ 생각 풍선이 退屈(지루함)를 보여 줌.
- 姓 '김' 예시 — 그대로. 가장 흔한 성으로 '성을 맨 앞에'를 구체적으로 보여 주고, 고정관념이나 불쾌한 요소 없음.
부품 이름 대조(모두 앱과 같음): 禺 = 날 일 + 짐승 발자국 유 = 원숭이 모양(遇·隅), 其 = 달 감 + 한 일 + 여덟 팔(棋), 丂 = 공교할 교(note 지팡이 모양, 考), 爿 = 나무 조각 장(将·状·荘), 𠂊 = 쌀 포(久·負·危).
고치지 않았지만 약한 카드: 없음
검수 완료: k2c03
