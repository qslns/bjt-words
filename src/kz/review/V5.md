# V5 검수 로그 (s02 s03 s04 s07)

## s02 (22장: 滞 軸 伺 撮 技 術 机 因 難 専 号 万 読 緒 皆 練 簡 束 厚 倍 究 葉)
validate: 오류 0 · 주의 0 (처음부터 0, 손댄 것 없어 그대로)

고친 카드
- 없음. 글 22장 전부 + 축소판 6장(p0~p5) 전부 확인함. 훈음·음독·훈독, 받침 규칙(촬 ㄹ→つ, 술 ㄹ→つ, 독·속·축 ㄱ→く, 인·난·전·만·간·련 ㄴ→ん, 엽 ㅂ→う, 후 ㅎ→か행)이 실제로 맞고, s: 경로 이름(伺 문틀 모양, 専 유, 号 구불구불 소리 모양, 読 책상 모양, 厚 날 일, 難 초두머리·입 구·지아비 부, 万 쌀 포)도 `info` 이름표/모양과 맞음. 練 p2는 크게 잘라 보아 糸 파랑·日 주황·木 초록 맞음.

고치지 않았지만 약한 카드
- 因 — '구덩이에 큰대자로 빠진 사람'은 囗大의 모양 연상일 뿐 진짜 어원(깔개 위에 누운 사람)은 아님. 사실이라고 단정하는 문장은 없고 '이거 때문이야!'로 뜻이 바로 보여서 둠.
- 皆 — p3 직접 그린 항목 28개(플래그)지만 축소판에서 흰 옷 입은 세 사람 + '다 같이!'가 또렷해서 둠.
- 軸 — p3 12개(플래그)지만 바퀴 + 빨간 막대 + 화살표로 또렷해서 둠.
- 厚 — '햇볕에 말린 이불'로 日을 끼워 넣은 건 조금 억지. 이불이 '두툼'하다는 뜻은 바로 보여서 둠.
- 滞·専·枼(葉)·号·読·万 — '띠 매듭 모양', '실 감는 막대 모양', '잎사귀 모양', '구불구불 소리 모양', '책상 모양', '쌀 포' 같은 조각 이름은 표준 훈음이 없는 부분에 붙인 정직한 'X 모양'이라 둠. 堇 '진흙 근'은 앱 이름표엔 없지만 표준 훈음임.
- 緒 bridge '一緒: 한 가닥 실로 이어져 함께'는 모양 연상 설명이지 어원 단정이 아니라 둠.

플래그 처리
- 机 '음차 의심' → 거짓 경보('책상'·'상(几)'의 '상').
- 読 '음차 의심' → 거짓 경보('책상'의 '상').
- 専 '一가 부품 목록에 없음' → 거짓 경보(s:1 가로획이 실제로 있음, tree도 s:1로 처리).
- 万 '勹가 부품 목록에 없음' → 거짓 경보(万 = 一 + 勹 모양, 2~3획이 勹 모양이라 tree도 s:2-3).

검수 완료: s02

## s03 (22장: 尋 悪 挨 拶 呼 銀 章 貿 菜 西 借 白 園 億 千 百 九 七 三 六 木 八)
validate: 오류 0 · 주의 0 (처음부터 0, 고친 뒤도 0)

고친 카드
- 尋 — tree 2단계 s:1-3 이름 '손 모양'(note '고슴도치머리 계(彐)라고도 해요') → 이름표대로 '돼지머리 계' + note '여기선 손 모양 · 부수 이름 튼가로왈'. s: 경로라 검사기가 못 잡았고, `info`에서 같은 부품(⺕/彐)이 '돼지머리 계'로 등록돼 있음(急·事와 같은 이름으로 통일). 축소판 다시 확인함.
- 西 — basic이 '새가 둥지에 든 모양을 그린 그림 글자예요'라고 단정 → '옛 풀이로는 …'으로 완화(새-둥지는 설문해자식 옛 풀이이고 현대 학설은 다름). 장면·그림은 그대로. 축소판 다시 확인함.

고치지 않았지만 약한 카드
- 拶 — '넘치는 시냇물을 손으로 꾹 눌러 막는' 장면은 현실적으로 좀 억지(물을 손으로 누를 수 없음). 하지만 '짓누를 찰'의 뜻은 보이고 挨拶 안에서만 쓰이는 글자라 둠.
- 挨 — '촉 달린 화살을 손으로 밀어 보내기'도 억지 연상. 矣=厶+矢 모양에는 맞고 뜻(밀칠)은 보여서 둠.
- 悪 — 亜를 '철창'으로 보는 건 모양 연상일 뿐이라 약함. 이름(버금 아)은 정직하게 '철창 모양으로 봐요'라고 밝혀서 둠. p3에 사람은 안 나오고 화난 얼굴+까만 마음만 나옴(hook의 '심술쟁이'는 그 얼굴).
- 千 — 十을 '날개 편 몸', 丿를 '갸웃한 고개'로 본 새 연상은 억지지만 하나의 장면이고 천 마리(뜻)가 보여서 둠.
- 九 — p1 캡션은 '꼬리는 아홉 개'인데 그림은 여우 얼굴만(꼬리는 p3에서 보임). 사소해서 둠.
- 木 — p3가 장면이라기보다 색칠한 木 + 부위 이름(가지·줄기·뿌리)이지만 그림 글자라 hook(가지·줄기·뿌리)과 맞아서 둠.
- 九·八·木 basic의 어원 설명(팔꿈치, 둘로 갈라짐, 나무)은 표준 설명이라 둠.

플래그 처리
- 悪 '한국음 악 ≠ 앱 음 오' → 거짓 경보(앱 훈음이 '악할 악 / 미워할 오' 둘이고, 악 → あく 설명은 맞음).
- 借 '廿가 부품 목록에 없음' → 거짓 경보(昔 윗부분 s:3-6이 실제 廿 모양, 이름 '스물 입' 표준 훈음).
- 白 '丿가 부품 목록에 없음' → 거짓 경보(s:1이 실제 삐침).
- 銀·六 hook 길이(53·56자) → 60자 이하, 그림이 또렷해서 둠. 九·七·六·八 p3 항목 많음 → 축소판에서 또렷해서 둠.

검수 완료: s03

## s04 (22장: 棚 駐 紹 介 祈 枚 隣 裏 輩 角 箱 秋 丁 寧 古 探 雨 誌 勉 困 筒 曲)
validate: 오류 0 · 주의 1 (寧 이름표) — 이유를 남기고 그대로 둠(아래)

고친 카드
- 曲 — basic이 '대나무로 엮은 굽은 바구니를 그린 그림 글자예요'라고 단정 → '옛 풀이로는 …'으로 완화(설문해자의 '굽은 그릇' 풀이를 바구니로 풀어 쓴 것이라 사실처럼 단정하면 위험). hook·그림은 그대로. 축소판 다시 확인함.

validate 주의 처리
- 寧.tree[0] '그릇 명' ≠ 이름표 '그물망머리' → 그대로 둠. KanjiVG가 이 조각(寍/罒, 8~12획)을 罒(원래 网)로 표시해서 이름표가 '그물망머리'지만, 寧의 이 부분은 실제로 皿(그릇 명)이고(설문해자도 '心在皿上'), hook·p1·mini가 모두 '밥그릇'이라 '그물망머리'로 바꾸면 오히려 틀려 보임. note '여기서는 그릇(皿) 모양'이 이미 붙어 있고, p2에서 이 조각이 초록색 그릇 모양으로 보임(크게 확인).

고치지 않았지만 약한 카드
- 介 — 아래 두 획은 실제로 丿丨(왼쪽 삐침 + 오른쪽 세로)라 완전한 八이 아님(플래그 '八가 부품 목록에 없음'은 이 때문). tree 이름은 '여덟 팔 모양(양쪽으로 갈라진 두 획)'이라 정직하고, 두 사람 사이에 끼인 장면이 紹介(소개)와 잘 맞아서 둠.
- 探 — '깊은 곳 모양'은 KanjiVG 묶음(㓁+木)에 이름을 붙인 지어낸 중간 조각이라 약함. 이름이 'X 모양'으로 정직하고 덮개 밑 더듬기 장면이 또렷해서 둠(後·向과 같은 판단).
- 駐 — p3 말 이모지가 달리는 모양이라 '세워 둠'과 조금 어긋나지만 '워워!'와 주차 표지(🅿️)로 뜻이 보여서 둠.
- 祈 — '도끼를 내려놓고 비는' 연상은 억지. 礻·斤 모양에는 맞고 '빌다'가 보여서 둠.
- 棚 — 선반 위에 달 두 개는 엉뚱하지만 朋의 月 둘 모양에 맞고 그림이 또렷해서 둠.
- 箱 — p3 12개(플래그)지만 상자를 들여다보는 두 사람이 또렷해서 둠.
- 角·雨·曲 basic(뿔·구름·바구니 그림 글자)은 곡 외에는 표준 그림 풀이라 둠.

플래그 처리
- 雨 '一·冂가 부품 목록에 없음' → 거짓 경보(1획 가로획과 2~3획 冂 틀이 실제로 있고 p2도 s:1, s:2-4로 칠함).
- 介 '八가 부품 목록에 없음' → 위 약한 카드 참고(모양 연상으로 허용).

검수 완료: s04

## s07 (22장: 警 察 英 婚 震 昔 壁 側 雪 複 薬 郊 季 興 鉄 友 飛 盛 趣 医 懸 命)
validate: 오류 0 · 주의 2 → 0 (雪 이름표, 複 이름표)

고친 카드
- 雪 — tree ⺕ 이름 '고슴도치머리 계'(note '여기선 빗자루 모양으로 봐요') → 이름표대로 '돼지머리 계' + note '여기선 빗자루 모양 · 부수 이름 튼가로왈'(validate 주의 해결, 事·急·尋과 같은 이름). 장면(빗자루로 눈 쓸기)은 그대로.
- 複 — tree 复 이름 '복 소리 부분'(훈음이 아닌 지어낸 이름) → 이름표대로 '돌아올 복', note '여기선 ‘되풀이’로 그려요'는 유지(validate 주의 해결). 축소판 다시 확인함(雪·複 둘 다 이름 칩만 바뀜).

고치지 않았지만 약한 카드
- 察 — 祭의 왼쪽 위 조각(s:4-7) 이름을 '육달월(원래 肉 · 몸·살)'로 씀. KanjiVG 이름표는 이 조각을 '달 월'이라 부르지만 祭는 손(又)으로 고기(肉)를 제단(示)에 올리는 글자라 '육달월'이 어원에 맞고, r06 際 카드도 같은 조각에 같은 이름을 씀. s: 경로라 검사기도 안 잡음. 일부러 둠.
- 興 — hook 57자로 길고 '손이 든 사람 모양'·'한 일(받침 판자)'은 모양 연상. 그래도 헹가래 한 장면이고 p3에서 또렷해서 둠. 命(54자)·銀·六도 길지만 60자 이하.
- 懸 — 縣 이름 '매달릴 현'은 libhangul 첫 뜻이라 표준, 단 県(고을 현)을 '깃발'로 보는 건 모양 연상일 뿐. hook·그림은 줄에 매달린 하트로 또렷해서 둠.
- 壁·薬·興·命 — '창문 달린 집 모양', '장식 끈 모양', '손이 든 사람 모양', '지붕 모양'은 KanjiVG 묶음에 붙인 정직한 'X 모양'이라 둠.
- 飛 — p1·p3 이모지가 올리브 가지를 문 흰 비둘기(🕊️)라 '평화' 느낌이 섞이지만 날개 편 새는 잘 보여서 둠.
- 婚 — 신부·신랑 장면은 女 모양에서 나온 것이고 결혼식 그 자체라 성별 고정관념으로 보지 않고 둠. 鉄의 '대장장이 아저씨'도 夫(지아비) 부품 때문이라 둠.

플래그 처리
- 察 '음차 의심' → 거짓 경보('제사상'의 '상').
- 興·命 hook 길이(57·54자) → 위 참고. 壁 p3 13개(플래그) → 축소판에서 집+말뚝+흙벽이 또렷해서 둠.

공통 메모 (V5 전체 · 88장 전수 확인)
- 자동 점검: 모든 p3 캡션 끝 '→ 앱 훈음'과 tree 마지막 결과 이름이 앱 훈음과 정확히 일치, 마지막 결과의 읽기(r)가 앱 음독 안에 있음, snd의 '한국음 X'가 앱 훈음의 음과 일치, '받침 ㄱ·ㄴ·ㄹ·ㅁ·ㅂ·ㅇ은 …' 규칙 말이 실제 받침·읽기와 모두 맞음, 가타카나·확장 한자(글에 보이는 것) 0, hook은 전부 '~모습'으로 끝남, 캡션 34자 이하·mini 45자 이하. tree 부품 이름을 KanjiVG 이름표와 stroke 단위로 대조해 불일치는 寧(아래 사유)·察(위 사유)뿐임을 확인.
- 寧 validate 주의 1건은 s04에 적은 이유로 남김(나머지 21 + s02/s03/s07은 주의 0).
- 확인 못 한 것: 실제 크기 미리보기(--sheet 아닌 것)는 열어 보지 않음(축소판 + 확대 잘라보기로만 봄). 아이패드/윈도/안드로이드 실제 기기에서의 이모지 모양·앱 화면의 note 표시 방식은 확인 못 함.

검수 완료: s07
