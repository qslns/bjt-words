# rk2c 검수 기록 (k2b01 · k2b02 · k2b03)

## k2b01 (28장) — validate 오류 0 · 주의 0
축소판 7장 전부 + 실제 크기(党·県·挙·環) 확인.

고친 카드
- 挙 — 두 팔 모양(s:4-6) note "원래 與를 줄인 꼴" → "위 점 셋과 함께 원래 與를 줄인 꼴". 與가 줄어든 것은 위 6획 전체(⺍+一+八)라서 어원 설명을 정확하게.
- 極 — p3 캡션 "꼭대기 끝까지 다 올랐다" → "다 올라요". 같은 카드 mini는 해요체이고, 앱 3,324개 캡션 중 '…했다' 평서 끝은 1개(그것도 감탄 '!')뿐이라 말투 통일. (k2b03 검수 뒤 말투 일괄 점검에서 찾아 고침 · 다시 그려 확인)

작성자 표시 항목 판정 (고치지 않음)
- 党 冖 = 덮을 멱 / 賞 같은 획 = 멀 경: 기존 앱과 같은 규칙. 尚로 묶는 堂·常은 "멀 경", ⺍·⺌ + 冖 + 아는 글자로 쪼개는 学·覚은 "덮을 멱". 党(小+冖+兄)은 学·覚 쪽, 賞(尚+貝)은 堂·常 쪽이라 둘 다 맞음.
- 県: 진짜 어원(거꾸로 매단 머리)을 피한 것 좋음. 장면이 어원이라고 말하지 않음. 'ㄴ자 받침 모양'은 정직한 모양 이름.
- 지어낸 모양 이름: 挙 '번쩍 빛 모양'은 기존 覚과 같은 이름. 疑 '물음표 모양'은 note가 "물음표(?)처럼 봐요"라 모양 연상으로만 씀(어원 단정 없음). 疑 '화살표 앞 사람 모양'(匕+矢, 표준 훈음 없음), 衆 '사람 셋 모양'(乑, libhangul에도 훈 없음), 監 '숙인 몸 모양'(기존 覧과 같음) — 모두 정직한 이름.
- 衆: tree 이름 '피 혈'은 정식 부수 이름이고 血은 앱에 카드로도 있음. 장면은 김 나는 솥 + 모인 사람들이라 피 그림 없음 → 부드러움 OK.
- 環: 고리(초록 원)가 ✋ 아래쪽(손목)에 오게 그려서 기기별 손 모양이 달라도 '손목에 낀 고리'로 보임. 睘 '눈·입·옷 모양'은 기존 還과 같은 이름.
- 爰 '당길 원'(暖·緩), 畐 '가득할 복'(富·副), 竟 '다할 경'(鏡), 韋 note(違), 脳 '머리 모양 のう'(悩) — 기존 카드와 일치.

약하지만 그대로 둔 카드
- 鮮: hook 끝이 "싱싱하고 고운 모습"이라 뜻을 형용사로 말함. 그래도 펄떡이는 물고기 그림이 '신선'을 바로 보여 줘서 둠.
- 環: 웃는 얼굴(罒·口)은 부품을 넣으려는 장치라 뜻(고리)과는 약하게 연결. 고리는 그림에서 분명해서 둠.

검수 완료: k2b01

## k2b02 (28장) — validate 오류 0 · 주의 0
축소판 7장 전부(작성자가 다시 안 그린 央 p3 캡션·撃 p2 색 포함) + 실제 크기(殺) 확인.

고친 카드
- 殺 — p3: 모기(🦟)가 작고 진한 초록 나뭇잎 위에 있고 굵은 빨간 X에 가려 축소판·실제 크기 모두에서 거의 안 보였음 → 모기를 키워(30) 나무 가장자리 밝은 바탕으로 옮기고 X를 가늘게, 파리채를 모기 위쪽에. 장면(모기를 탁! 잡는 모습)이 이제 보임.
- 湾 — snd "弯 = わん → 湾도 わん (받침 ㄴ은 ん)"에서 받침 규칙이 걸릴 한국음이 빠져 있었음 → "· 한국음 **만** → わん (받침 ㄴ은 ん)"으로.

작성자 표시 항목 판정 (고치지 않음)
- 央 p3 캡션 "문틀 한가운데 딱! → 가운데 앙", 撃 p2 색(車 초록·殳 주황·手 파랑): 다시 그려 확인, tree 색과도 맞음.
- 撃(수레 위 북을 북채로 둥!)·攻(연장으로 성문 쾅쾅): 부드럽지만 '세게 치다'가 장면에 그대로 보이고, bridge가 攻撃(공격)으로 이어 줌 → 뜻 전달 OK.
- 殺: 카드 글(hook·bridge·캡션·tree·snd) 어디에도 自殺 없음(grep 0). 단, 아래 '확인 못 한 것' 참고.
- 兵: 💂 옆에 도끼를 세워 둔 그림, 누구도 겨누지 않음 → OK. 廾 → '받들 공'은 기존 算·弁과 같은 이름.
- 谷: hook 44자 — 기준(45자 안팎) 안. 산비탈(八) 겹겹 + 골짜기 입구(口)는 실제 옛 풀이와 같고 그림(산 둘·물방울)도 맞음.
- 扁 '작을 편': libhangul 훈에 '작을 편'이 있음(넓적할 편은 없음). mini가 "작고 넓적한"으로 둘 다 품음 → OK.
- 弯 '굽을 만': 弯은 彎의 약자이고 彎의 표준 훈음이 '굽을 만' → OK.
- 그 밖 이름도 기존 카드와 일치: 尞 '모닥불 모양'(僚), 爿 '나무 조각 장'(将·状), 虍 '범호엄'(慮), 叔(寂), 建(建), 各(各), 公(公), 可(可), 亦 '또 역'(変), 殳 '갖은등글월문'(設·投). 豦·乑처럼 libhangul에 훈이 없는 것만 '…모양'.

약하지만 그대로 둔 카드
- 劇: 앱 훈음 '심할 극'과 달리 장면은 일본어 뜻(연극)을 따름 — K2B 지침대로이고 bridge가 '아슬아슬 심한 장면 → 극'으로 이어 줌.

확인 못 한 것 / 메인 세션에 넘길 것
- 殺 카드 아래 '단어' 줄은 앱 단어 자료에서 자동으로 들어가서 미리보기에 **自殺 じさつ 자살**이 보임. 배치 파일로는 못 막음 — 앱 단어 자료나 한자 카드 단어 줄에서 빼야 K2B 지침(自殺은 카드 어디에도 안 됨)이 지켜짐.

검수 완료: k2b02

## k2b03 (27장) — validate 오류 0 · 주의 1(皇, 아래 이유로 유지)
축소판 7장 전부 + 실제 크기(岩) 확인.

고친 카드
- 王 — basic "위 가로획은 하늘, 아래 가로획은 땅, 가운데 十은 두 팔 벌리고 선 사람 — …"이 획의 뜻을 사실처럼 단정(실제 어원은 큰 도끼 모양, 옛 풀이는 三+丨). → "…선 사람**으로 보면** — …"으로 모양 연상임을 밝힘. hook·그림은 그대로.

작성자 표시 항목 판정
- 皇 아래 王 = '임금 왕'(이름표 '구슬옥변'과 다름, validate 주의) → **유지**. KanjiVG가 같은 줄에 '원래 玉'과 '소리 부분 王'을 함께 달아 스스로 모순이고, 皇의 소리 おう는 王(おう)에서 옴(玉은 ぎょく). 부수도 白이고 일반 풀이도 '관(白)을 쓴 임금(王)'. 王 카드 basic도 "다른 글자 **왼쪽에** 붙은 王 모양은 대개 구슬옥변"이라 하므로 아래에 놓인 皇의 王과 충돌 없음.
- 串 '꿸 관': kzc.py hun에 이름표·앱 훈음 없음. libhangul은 "곶 / 관 / 꿸 천", 웹 사전도 엇갈림(hangulhanja '익힐 관', 위키낱말사전 '꿰미 천·땅 이름 곶'). '꿸 관'은 꼬치 뜻 + 患(환)이 쓰는 관 소리를 합친 것으로, 한국 한자 풀이에서 흔히 쓰는 이름이라 유지 — 다만 표준 사전 대표 훈음인지는 끝까지 확인 못 함(아래 참고).
- 莫 r "も・ぼ": 模의 앱 읽기가 も・ぼ이고 info의 莫 읽기(ばく・ぼ・まく・も)에도 둘 다 있음. 기존 募·暮는 자기 읽기 ぼ만 보여 준 것이라 모순 아님 → 유지.
- 婦: 부부가 빗자루 하나씩 들고 새집을 같이 쓰는 장면 — 고정관념 없음, 단어(夫婦·主婦·婦人)와도 맞음 → 유지.
- 葬: "돌아가신 분", 풀 언덕 + 꽃다발 + 비둘기 — 부드러움 OK. p1의 死는 🥀(시든 꽃)로.
- 乱: 도형으로 그린 말풍선("어버버")이 축소판·제자리에서 잘 보임 → 유지.
- 기존 카드와 이름 일치 확인: 莫(募·暮), 帚(掃·帰), 青 '날 생 모양'(青·精), 云(雲), 共(共·異), 坴 '겹친 흙 모양'(熱), 舌(話), 色(色), 丁(丁), 成(成), 隶 '미칠 이'(이름표). 尃는 libhangul 훈 없음 → '펼친 표 모양' 정직한 이름.

약하지만 그대로 둔 카드
- 乱: 😵🌀 그림이 '어지럽다'를 어지럼증 쪽으로도 읽히게 하지만, hook·캡션이 '말이 뒤죽박죽'(혼란)이고 bridge가 '흐트러지다'로 잡아 줌.
- 岩: p3 '끄떡!' 글자가 바위 오른쪽 끝에 살짝 걸침 — 읽는 데 문제없어 둠.

확인 못 한 것
- 串의 표준 대표 훈음(네이버 등 표준 한자사전 직접 확인 못 함). 다른 이름이 맞다면 患 tree의 串 이름 두 곳만 바꾸면 됨(장면·소리 사슬 かん은 그대로).

## 세 배치 공통 자동 점검 (내가 돌린 것)
- 가타카나 0, hook 전부 '모습'으로 끝·50자 이하, 캡션 34자 이하, p3 끝 = 앱 훈음, 마지막 res 이름 = 앱 훈음.
- tree의 모든 r(소리 부분·중간 결과·최종)이 앱 읽기/부품 읽기 자료에 있음. 예외는 脳 '머리 모양 のう' 하나인데 기존 悩 카드와 똑같은 표기라 유지.
- snd의 받침 규칙 줄 전부 실제로 맞는지 한 자씩 확인(틀린 규칙 0).

검수 완료: k2b03
