## k2b07 (27장) — validate 오류 0 · 주의 0, 축소판 p0~p5 전부 확인
고친 카드: 없음

작성자 표시 항목 판단:
- 柄 자루+무늬 함께: 앱 단어 柄(がら 무늬)와 훈음 자루를 한 장면에 담아 좋음 → 그대로
- 滅 戌을 화로로: tree 이름은 정식 '개 술' + note '여기선 화로' → 그대로
- 敷 旉 건너뜀(甫+方+攵 한 단계): 부품 3개 허용 범위, 旉는 드문 글자 → 그대로
- 酸 夋 '천천히 걷는 사람 모양': libhangul에 훈 없음(준) → 정직한 'X 모양' 이름 → 그대로
- 敵 啇 '밑동 적': 이름표·기존 카드(適·摘)와 같음 → 그대로
- 寿 snd 寿司(すし)의 す: 앱 음독 す, 단어 읽기로 표시돼 있음 → 그대로
- 殿 snd どの = との가 흐려진 소리(연탁): 사실 → 그대로
- 🪶 🪣 (Emoji 13.0) 허용
- 그 밖에 확인: 旗 '깃발 모양'·梅 '머리 장식'·桜 '점 셋'은 기존 카드(旅·族·遊 / 毎 / 学·労)와 같은 이름. 匈 '가슴 흉'(libhangul 흉:가슴), 甫 '클 보', 丙 '남녘 병' 표준.

약하지만 두는 카드:
- 兆: '금이 1조 갈래로' 과장으로 '조'를 잇는 장면 — 뜻은 바로 보이므로 둠
- 梅 p3: 원을 18개 직접 그렸지만 축소판에서 매화 세 송이로 또렷이 보임(벚꽃 🌸과 구별) → 둠
- 圏 snd: 巻의 けん은 드문 음독(KANJIDIC에는 있음) — 사실이라 둠

## k2b08 (27장) — validate 오류 0 · 주의 0, 축소판 p0~p6 전부 확인
고친 카드:
- 勇 — tree s:1-7 note를 '아래 用이 田 모양으로 바뀐 꼴(通·踊의 甬) · 여기선 손잡이 달린 방패'로: 축소판에서 이 조각은 マ+田 모양이라 hook의 甬(用 들어감)과 다르게 보임 → 같은 부품인데 모양이 바뀐 것임을 밝힘(이름 '골목길 용'은 이름표·通·痛·踊 카드와 같아 그대로)
- 慢 — bridge에 我慢(참음) 잇기 추가: '→ 우쭐하다 · 뽐내다 (自慢 자랑) · 我慢(참음): 원래 ‘내가 잘났다’는 고집 → 꾹 버팀'. 장면(우쭐)과 앱 단어 我慢(참음)이 그냥 나란히만 있어 왜 참음인지 안 이어졌음(我慢은 불교어 '아만'=자만 → 고집 → 참음, 사실)

작성자 표시 항목 판단:
- 誇 '받침대 모양': 아래 조각 亏는 libhangul에 훈 없음(우/휴) → 정직한 'X 모양' 이름, 그대로
- 煙 火+覀+土 한 단계: 垔은 드문 글자, 부품 3개 허용 → 그대로
- 墓 해 질 녘 🪦 앞에 꽃 놓고 무릎 꿇은 사람: 성묘 장면, 무섭거나 슬프지 않음 → 그대로
- 殊 歹를 '앙상하게 마른 꽃'(🥀): 죽음 대신 시든 꽃, 이름 '뼈 앙상할 알'은 기존 死·残과 같음 → 그대로
- snd가 가리키는 다른 카드 읽기 전부 앱 자료에 있음: 僕 ぼく · 億 おく · 基 き · 期 き · 暮 ぼ · 募 ぼ · 漫 まん · 帽 ぼう · 順 じゅん
- 이름 일관성: 菐 '번거로울 복'(僕), 歹(死·残), 穴 '구멍 혈' + 宀+八(究·空), 冒 = 日(모자)+目(帽) — 기존 카드와 같음

약하지만 두는 카드:
- 腰: 바구니(覀) 인 여자(女)가 허리 짚는 장면 — 집안일 고정관념은 아니고, 要는 원래 허리에 손 얹은 여자 그림이라 둠. hook의 '몸(月)의 허리를'은 조금 어색
- 棋: 앱 단어는 将棋(장기)인데 장면은 바둑 — 훈음이 '바둑 기'라 맞고 bridge가 将棋를 이어 줌
- 撲: 손바닥으로 스모 선수를 '탁!' — 스모 경기 동작이라 둠

검수 완료: k2b08

## k2b09 (27장) — validate 오류 0 · 주의 0, 축소판 p0~p5 전부 확인 (欄은 실제 크기로도 확인)
고친 카드:
- 欄 — 안쪽 부품(闌/柬, 획 13-20)은 8획이라 실제로 그려지는 모양이 **東**(머리 글자·tree 상자 모두 東)인데, hook·p1·p2·mini는 柬, 이름은 '가릴 간', note는 '束(묶을 속)과 닮은 꼴'이었음(모양 설명이 틀림). 앱의 練 카드(같은 柬→東 줄임)처럼 hook·캡션·mini를 (東)으로, tree 이름 '동녘 동' + note '원래 **柬**(가릴 간)이 줄어든 꼴 · 여기선 나무 다발'로. 결과 '闌 가로막을 란'은 그대로(闌는 글자로는 柬이 든 꼴로 나옴 — 바꿀 글자가 없음)
- 荘 — hook·p2 캡션·mini의 평상(爿) → 평상(丬): 荘에 실제로 있는 건 3획 丬(획 4-6). 앱 将 카드·k2b02 装과 같은 표기. tree 이름 '나무 조각 장' + note '원래 爿'은 그대로
- 懐 — 2단계 부품 s:4-16에 note '옛 글자 **褱**(품을 회)가 줄어든 꼴' 추가: 상자에는 十+罒+衣(요즘 모양)가 그려지는데 이름표는 褱라서 모양 차이를 밝힘

작성자 표시 항목 판단:
- 业 이름 셋(業 '늘어선 물건 모양' / 虚 '언덕 모양' / 顕 '실 모양'): 모양은 같지만 출신이 다름 — 虛는 丘(언덕), 顯은 㬎의 絲(실), 業은 종 거는 틀. 각 note가 '원래 丘/絲'를 밝히고 장면과 맞음. 하나로 합치면 장면과 어긋남 → 그대로(같은 부품 다른 이름이 의도된 예외)
- 闌 '가로막을 란': 표준 훈(libhangul '가막을'은 오타) → 그대로
- 欄 장면이 난간인데 앱 단어는 기입란: 훈음 '난간 란'이 곧 장면이고, hook의 '칸칸이' + bridge '난간처럼 칸칸이 나뉜 곳 → 서류의 칸 · 기입란'이 이어 줌. 한국어도 '기입란·비고란'에 '란'을 쓰니 연결이 자연스러움 → 장면 그대로
- 懐 중간 이름 褱: 기존 壊 카드는 같은 조각을 '그물 덮인 옷 모양'으로 부름. 懐에서는 褱(품을 회)가 소리(かい)이자 뜻(품다)이고, 장면도 罒을 '눈물 맺힌 눈'으로 읽음(褱=衣+眔, 眔=눈물 흘리는 눈 — 실제 어원) → '褱 품을 회' 유지, note로 모양 차이만 밝힘
- 毒 엄마가 '먹으면 안 돼!' 말리는 장면: 부드러움, 집안일 고정관념 아님 → 그대로. 龶 '날 생 모양'은 앱 青·精과 같은 이름
- 🥲 (Emoji 13.0) 허용
- 그 밖 이름 확인: 虍 '범호엄'(慮와 같음), 脈 '갈래 모양'(派와 같음), 爿 '나무 조각 장'(将·状과 같음), 竜 '용 룡', 圭 '서옥 규', 厓 '언덕 애', 此 '이 차', 柬 '가릴 간'

약하지만 두는 카드:
- 氷 p3: 색칠한 氷 글자 옆에 🧊·❄️를 둔 정도라 '장면'은 약함. 그래도 점(丶) 옆 얼음이 보여 뜻은 전달됨
- 脈 p3: 사람 몸 윤곽에 빨간 핏줄 선 — 해부도처럼 깔끔하고 피·상처는 아님
- 才: hook 안에 '재주'라는 뜻말이 그대로 들어감(장면 = 떡잎부터 남다른 새싹) — 뜻은 바로 보임

검수 완료: k2b09
