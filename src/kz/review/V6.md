# V6 검수 로그 (s08 s09 s10 s11)

방법: 배치마다 글 22장 전부를 압축 덤프로 읽고(점검표 1~6), 축소판(--sheet) 6장씩 전부 확인. 한국음 = 앱 훈음 끝 글자, 받침 규칙, snd의 읽기 vs 앱 음독·훈독, 가타카나, 확장 한자, 부품 이름의 이름표·다른 카드와의 일치를 스크립트로도 한 번 더 돌려 봄. 고친 카드는 축소판을 다시 만들어 다시 봄.

## s08 (22장: 包 局 久 掃 喫 符 辺 傘 弱 抵 汚 貸 珍 寒 冊 飯 狭 奥 寝 坊 亡 嬉)
validate: 오류 0 · 주의 1 → 0 (抵 이름표)

고친 카드
- 抵 — tree 氐 이름 '근본 저'(중간 결과 '氐 근본 저' 포함) → 이름표대로 '낮을 저'. validate 주의 해결이고, 같은 조각을 쓰는 低(r06)·底(s11)와 이름도 맞춤. 축소판 다시 확인함.

고치지 않았지만 약한 카드
- 喫 — 丰를 '채소'로 보고 tree 이름도 '풀 모양'인데, 같은 조각을 契(s09)는 '눈금 새긴 막대 모양'으로 부름. 각 카드 이야기 안에서는 맞아서 둠(카드 사이 이름만 다름).
- 久 — 勹=허리 굽은 할머니, 乀=지팡이는 모양 연상일 뿐 어원은 아님(단정 문장은 없음). p1·p3의 👵는 허리가 굽어 보이진 않지만 지팡이가 보여서 '오래 산' 뜻은 전달됨.
- 汚 — 亏를 '웅덩이 모양'으로 보는 건 억지 연상. 이름이 정직한 'X 모양'이고 p3 장면(웅덩이 물이 튀어 옷이 더러워짐)이 또렷해서 둠.
- 亡 — 관 속에 누운 사람이라는 소재가 어두운 편. 글은 '세상을 떠난'으로 부드럽고 p3는 꽃·비둘기뿐이라 둠.
- 辺·奥·坊·抵 — 앱 훈음(가 변·깊을 오·동네 방·막을 저)과 단어 뜻(근처·奥さん·寝坊·大抵)이 달라 bridge가 이어 주는 구조. 지침(앱 훈음/단어 뜻) 대로라 둠. 抵는 hook의 '선(一) 앞'과 p3 세로선이 글자 속 위치(氏 아래 一)와 다르지만 '막다'가 바로 보임.
- 弱 — 활에 얼음이 매달리는 장면은 물리적으로 어색하지만 '축 처짐'이 보이고 부품 넷이 다 나옴.

플래그 처리
- 久 '乀가 부품 목록에 없음' → 거짓 경보(久의 3번째 획 '파임 불', tree s:3에 이름 있음. 乀는 기본 한자 영역 글자).
- 喫 '丰가 부품 목록에 없음' → 거짓 경보(KanjiVG 이름이 같은 모양의 龶).
- 汚 '亏가 부품 목록에 없음' → 거짓 경보(KanjiVG '亏V' 소리 부분 표시, 기본 영역 글자).
- 辺 p3 10개 → 길·칼·바다 또렷함. 둠.

검수 완료: s08

## s09 (22장: 酒 師 販 容 採 宣 推 罪 需 異 誠 詫 策 契 赤 僚 刺 踏 至 針 旧 依)
validate: 오류 0 · 주의 0 (처음부터 0, 손댄 것 없어 그대로)

고친 카드
- 없음. 글 22장 전부 + 축소판 6장(p0~p5) 전부 확인함. 읽기·한국음·받침 규칙(책 ㄱ→く, 적 ㄱ→き, 답 ㅂ→う, 산·판·선·침 ㄴ·ㅁ→ん, 용 ㅇ→う)이 실제로 맞고, tree 이름(酉 닭 유, 乂·厶·朿 등)도 이름표·표준 훈음과 맞음. 罪·策은 p3를 3배로 키워 보았고 그물·울타리가 또렷함.

고치지 않았지만 약한 카드
- 詫 — hook은 '사과'(お詫び)인데 앱 훈음은 '자랑할 타'라 p3 끝이 '사과 장면 → 자랑할 타'가 됨. 지침(단어 뜻 쪽)대로이고 bridge가 '일본에서는 사과하다'로 이어 줌.
- 容 — hook은 '담다·내용'(内容), 앱 훈음은 '얼굴 용'. bridge가 '얼굴 모습'까지 이어 줌.
- 師 — '흙단 위에서 수건 깃발 흔드는 선생님'은 설정이 억지스럽지만 부품(흙더미 모양·막대·巾)이 다 보임.
- 旧 — '해시계'는 모양 연상(旧의 어원 아님). '원래 ~였다'고 단정하는 문장은 없어 둠.
- 契 — 龶 조각 이름 '눈금 새긴 막대 모양'은 喫과 다름(위 喫 참고). 契 자체는 진짜 어원(칼로 막대에 눈금)과 맞음.
- 罪 p1 17개·p3 19개, 策 p3 21개 → 그물 격자·대나무 울타리 선이라 항목 수만 많고 또렷함.

플래그 처리
- 罪·異·策 '그림 항목 많음' → 위와 같이 또렷해서 둠.

검수 완료: s09

## s10 (22장: 渉 惑 添 条 継 摘 訂 影 響 悩 捗 抜 第 占 幸 概 黒 均 賜 舗 緊 敬)
validate: 오류 0 · 주의 1 → 0 (摘 이름표)

고친 카드
- 摘 — tree 啇 이름 '가지 끝 열매 모양' → 이름표대로 '밑동 적' + note '소리 부분 · 여기선 가지 끝에 열매가 달린 모양'. validate 주의 해결, 適(r10)과 이름 통일. hook·그림은 그대로(열매 장면 유지). 축소판 다시 확인함.
- 渉 — snd의 '少(적을 소)=しょう → 渉도 しょう'는 少가 소리 부분이라는 근거가 없음(渉은 氵+歩의 뜻 합친 글자이고 少는 歩 속 조각, 같은 歩가 든 捗는 ちょく). '한국음 섭 → しょう (받침 ㅂ은 う로)'는 남기고, 少는 '歩 안에 든 少(적을 소)도 しょう'라고 사실만 적음. 축소판 다시 확인함.
- 惑 — p2에서 口와 一을 같은 보라로 칠해 tree 칩(一은 다른 색)과 안 맞았음 → 一을 초록으로. p2·tree 칩 색 일치 다시 확인함.

고치지 않았지만 약한 카드
- 捗 — '척!/척척'이 소리 놀이처럼 보일 수 있지만 '일이 척척 진행된다'는 실제 뜻(進捗·捗る)과 이어진 자연스러운 의성어라 둠. ✋가 70° 돌아 있으나 손바닥 그림이라 기기마다 모양이 달라도 '등을 미는 손'으로 읽힘.
- 幸 — hook 53자(긴 편, 60 이하). 화살 둘·방패 든 사람이 장면에 다 나옴.
- 慎(s11 참고)와 달리 敬·賜 — 막대 든 어른, 윗사람/아랫사람 같은 위계 장면이지만 폭력·차별 표현은 없어 둠.
- 継·抜·添 — 지어낸 중간 조각('끊어진 실 모양', '왼손 모양', '기울어진 사람 모양')은 표준 훈음이 없는 부분에 붙인 정직한 'X 모양'이라 둠.
- 摘 — 啇(밑동)을 열매로 보는 건 모양 연상(소리 부분이라는 사실은 맞음).

플래그 처리
- 舗 '舎가 부품 목록에 없음' → 거짓 경보(왼쪽이 실제로 舎=人+吉이고 KanjiVG에 이름 없는 묶음일 뿐).
- 惑·条·継·抜·幸 p3 10~14개 → 축소판에서 또렷함. 둠.

검수 완료: s10

## s11 (22장: 海 帯 域 啓 析 希 伴 演 唱 維 票 雰 囲 把 握 慎 我 徹 底 迅 拓 秘)
validate: 오류 0 · 주의 1 → 0 (把 이름표)

고친 카드
- 把 — tree 巴 이름 '뱀 파' → 이름표대로 '꼬리 파' + note '똬리 튼 뱀 모양 · 뱀 파라고도 해요'(色(r13)과 같은 표기). validate 주의 해결. hook·p1(뱀 그림)은 그대로. 축소판 다시 확인함.

고치지 않았지만 약한 카드
- 帯·雰 — p3 18개·22개(플래그)지만 3배로 키워 보니 띠 맨 사람·안개 낀 집과 나무가 또렷함(雰은 연한 편). 둠.
- 唱 — 해 둘이 하늘에 뜬 장면은 비현실적이지만 昌(日日) 모양 그대로. 둠.
- 慎 — hook 51자, 十이 장면에 안 나옴(p2 캡션엔 있음). 눈(目)·다리(一)·두 발(八)이 위에서 아래로 놓인 모양과 맞아서 둠.
- 我 — '창을 쥔 사람'인데 p3는 창이 사람 옆에 세워져 있음(👈로 가슴을 가리킴). '나야, 나!'로 뜻은 보임.
- 域 — p3 14개지만 울타리·병사·창 또렷.
- 希 — 乂를 '엇갈린 손가락'으로 보는 건 모양 연상(어원은 천을 성기게 짠 모양). 단정 문장 없어 둠.

플래그 처리
- 我 '手가 부품 목록에 없음' → 거짓 경보(왼쪽 조각이 手 모양, tree엔 '손 모양'으로 정직하게 표시).
- 帯·域·演·雰·徹 p3 항목 많음 → 위와 같이 또렷해서 둠.

검수 완료: s11

## 전체 메모 / 확인 못 한 것
- 실제 크기 미리보기는 만들어 보지 않았음(축소판 + 복잡한 p3 4장을 3배로 확대해 확인).
- 아이패드 실기기에서 丰·亏·乀·丗·覀·夭·从·爿·乂·氐·夹·匀·卂·尞 같은 드문 글자가 네모로 나오는지는 확인 못 함. 모두 기본 한자 영역(U+4E00~9FFF)이고, 확장 한자·한자 부수 보충 문자는 화면에 보이는 글에 하나도 없음(스크립트로 확인).
- 이모지 모양·방향의 기기별 차이는 확인 못 함(회전은 ✋ 70°·🎤 -20° 외엔 ±20° 이내).
- 어원 사실성은 KanjiVG·MakeMeAHanzi 정보와 내 지식으로만 대조함(사전 원문은 조회하지 않음).
- p2 색 vs tree 칩 색: 부모 조각을 한 색으로 칠하고 같은 단계의 하위 조각이 자동으로 다른 색을 받는 경우(掃·傘·貸·宣·渉·添·訂·捗·抜·敬·海·秘 등)는 도구 구조상 생기는 것이라 손대지 않음. 寝은 두 손(彐·又)을 같은 보라로 묶은 것이 의도라 둠.

검수 완료: s11
