고친 카드
- 護 — snd "語도 言(말)이 붙고 ご"를 뺌: 言이 ご 소리를 내는 것처럼 읽히는 근거 없는 규칙. → "한국음 호 → ご · 保護 ほご(보호)"
- 護 — 蒦 이름 '풀 속 새 잡기 모양' → '풀숲 속 새 모양' (같은 부품을 쓰는 獲(r31)과 통일)
- 富 — 畐 이름 '항아리 모양' → 이름표대로 '가득할 복'(note '배부른 항아리 모양'), 중간 결과 '畐 가득할 복', p1 캡션도 맞춤
- 償 — 尚 이름 '작은 창구 모양'(지어낸 이름) → 표준 '尚 오히려 상'(常·堂 카드와 통일), 창구 연상은 note '여기선 작은 창구 모양'으로
- 幹 — 왼쪽 조각(十+早) 이름 '햇살 모양' → '풀숲 사이 해 모양'(朝(r08)과 같은 부품이라 통일), mini도 그에 맞춤

약하지만 그대로 둔 카드
- 旨 — '뜻'이 원래 추상적이라 장면이 "떠먹여 주듯 ‘이게 내 뜻!’" 관용 비유에 기댐. p3도 숟가락+입+대사뿐. 틀린 곳은 없어 유지.
- 遣 — hook의 눈(目)은 실제로는 目 비슷한 조각(㠯). tree에서 '눈 목 모양 · 目처럼 생긴 조각'으로 솔직하게 적혀 있어 유지(자동 점검 '目 부품 없음' 경보의 원인).
- 慶 — hook에선 广을 '집'으로, tree에선 广이 사슴(鹿) 윗부분의 일부로 묶임. 이름은 정식이라 유지.

자동 점검 경보 처리
- 括·革·旦·幹·測 'p3 항목 10개 이상' — 선·도형 조각 수일 뿐 축소판에서 장면이 또렷함(틀·가죽, 해돋이, 나무 줄기, 눈금 줄). 유지.
- 賠·償 '음차 의심' — '배상·보상'의 '상'에 걸린 거짓 경보.
