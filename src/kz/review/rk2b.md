## k2a04 (27장)

validate: 처음 오류 0 · 주의 0 → 고친 뒤에도 오류 0 · 주의 0.
축소판 p0~p5 전부 확인(27장). 의심 카드 飾·杯·卵은 실제 크기로도 확인.

### 고친 카드
- 杯 — p3: 엎어 놓은 잔(손잡이 달린 둥근 모양)이 종처럼 보임 → 상 위에 🍶(술병)을 놓고 잔·사람 위치를 조정해 '마신 잔'으로 읽히게 함. 다시 그려 확인.
- 祖 — tree 且 note "원래 조상의 위패를 그린 글자"(여러 풀이 중 하나를 사실처럼 단정) → "여기선 조상의 위패 모양 · 옛 글자에선 且가 곧 祖"(갑골문에서 且로 祖를 씀 = 사실). 장면·이름(또 차)은 그대로.
- 腹 — snd "お腹는 おなか"가 腹의 훈독처럼 읽힐 수 있음 → "단어 お腹는 통째로 おなか"로 단어 읽기임을 분명히.
- 湖 — (k2a06 絹 판정 뒤 같은 기준으로 다시 고침) 胡의 月은 원래 肉(胡는 肉부, 설문 '从肉古聲')인데 tree 이름이 '달 월' → '육달월' + note "원래 肉(고기 육) · 여기선 달 모양으로 봐요"(기존 朝 카드와 같은 처리). 경로 `胡/月` → `s:9-12`(같은 획, 기존 際·察·然 카드처럼 이름표 '달 월' 주의를 피하는 방식). p1 캡션 "달 월(月)" → "달(月)"(장면 이름). 장면(호수에 비친 달)은 그대로. 다시 그려 확인.

### 작성자 의문 판정
- 菐 '번거로울 복': 유지. 도구엔 음(복)만 있지만 한국 한자사전 관례 훈이 '번거로울 복'이고, 영어 풀이(tedious = 번거롭다)와도 맞음. 다른 카드에 菐 없음(충돌 없음).
- 杯 잔이 종처럼 보임: 맞음 → 위처럼 p3에 🍶 추가로 고침(p1은 不 모양 연상이 핵심이라 유지).
- 黄 옛 풀이(田+光): 유지. basic에 "옛 풀이로는"이라고 밝혀 단정하지 않음(설문해자 풀이 = 사실대로 표시).
- 乳 🤱: 유지. Emoji 5.0, 모든 기기에서 아기를 안은 얌전한 그림이고 '젖'을 가장 바로 보여 줌. 👩‍🍼(13.0)로 바꾸면 '젖' 뜻이 약해짐.
- 腹 お腹 おなか: 단어 읽기로 분명히 표시하도록 고침(위).
- 祖 且=위패: 장면은 유지(이 한자 뜻을 가장 바로 보여 줌). 이름 '또 차'는 組·助·査·狙 카드와 같음. note만 단정하지 않게 고침(위).

### 고치지 않았지만 약한 카드
- 湖 — '오래된(古)'은 그림으로 못 그리는 형용사. 다만 호수+비친 달 장면이 뜻을 바로 보여 줘서 유지(月 이름만 위처럼 고침).
- 湯 — 햇볕에 물이 끓는 장면은 실제로는 무리. ♨️로 '뜨거운 물'은 바로 보여서 유지(場 카드와 昜 쪼개기 동일).
- 牛·犬·耳 — p3가 '이모지 → 한자' 형태라 金 샘플 日보다 장면성이 약함. 그림 글자라 허용 범위로 봄.

### 확인 사항
- 읽기: snd·bridge의 읽기 전부 앱 음독·훈독에 있음. 先祖 せんぞ·乾杯 かんぱい·お兄さん おにいさん은 단어 읽기로 표시돼 있음.
- 받침 규칙 17곳 전부 실제로 맞음(泣 읍→きゅう는 첫소리는 다르지만 받침 ㅂ→う는 맞음).
- 이름 통일: 甬(痛)·昜(場)·戔(残)·复(復·複)·云(会·転·曇·伝)·且(組·査·助·狙) 기존 카드와 같은 이름.
- 卵 p2 색: 획 4가 왼쪽 알 쪽(KanjiVG 卯/丿)이라 작성자 색 나눔이 맞음 → 그대로.
- 가타카나 0, hook 전부 '모습'으로 끝남, 캡션 길이 초과 없음(스크립트로 확인).

## k2a05 (27장)

validate: 처음 오류 0 · 주의 0 → 고친 뒤에도 오류 0 · 주의 0.
축소판 p0~p6 전부 확인(27장).

### 고친 카드
- 眼 — snd "훈독 め(눈) → 眼鏡 めがね"가 め+がね로 나뉘는 것처럼 읽힘(眼鏡는 숙자훈, 鏡에 がね 읽기 없음) → "훈독 め(눈) · 단어 眼鏡는 통째로 めがね(안경)". 다시 그려 확인.

### 작성자 의문 판정
- 乞 '빌 걸': 유지. 검정·교육용 표준 훈음이 '빌 걸'(hangulhanja.com 확인). libhangul의 '구걸할 걸'은 같은 뜻 풀어쓰기. 기존 카드에 乞 없음.
- 并 '아우를 병': 유지. 기존 併 카드와 같은 이름.
- 髟 '머리 늘일 표': 유지. libhangul 훈 목록에 그대로 있음.
- Emoji 13.0(🪞 🪝 🪙 🪣): 유지. 지침 기준이 13.1 이하이고 승인된 金 샘플 確도 🪨(13.0)를 씀. iOS 14.2 미만 기기는 걱정거리로만 남김.
- 妹 p3 👩/👧 크기 차이: 유지. 👧는 기기마다 '어린 여자아이'로 그려지고 크기·까치발 화살표·hook 글이 함께 받쳐 줌.
- 眼 眼鏡 めがね: 위처럼 '단어 통째 읽기'로 고침.
- '해 돋는 모양'(乾 왼쪽): 유지. 그 조각(𠦝)은 확장 한자라 글에 못 쓰고 표준 훈도 없음 → 지침의 정직한 'X 모양' 이름. 뜻도 倝(해 돋을 간)과 맞아 오해 없음.
- '막대 쥔 손 모양'(糖 s:10-13): 유지. ⺕+세로획(肀 꼴)이라 표준 훈 없음. 따로 쪼개면(⺕ 돼지머리 계 + 丨) 한 단계 부품이 4개가 됨. note에 손(彐)+막대(丨)라고 밝혀 둠.

### 고치지 않았지만 약한 카드
- 漫 — 🥅는 축구 골대 그물이라 '고기잡이 그물'로는 조금 어색. hook 글·손·튀는 물방울이 있어 장면은 읽힘. 13.1 이하에 고기잡이 그물 이모지가 없음.
- 靴 — '변신'은 전/후 두 상태(가죽 → 화살표 → 구두)라 한 장면보다는 짧은 과정. 뜻(구두)은 바로 보여서 유지.
- 髪 p1 — 長을 👱‍♀️(긴 머리)로 보여 줌. 조금 억지지만 p2·tree가 長을 정식으로 보여 줘서 유지.
- 匹 — 匸의 정식 이름은 '감출 혜(터진에운담)'이지만 이름표가 '상자 방(터진입구몸)'이고 기존 区 카드와 같아서 통일 쪽으로 유지.

### 확인 사항
- 이름 통일: 关(送 '손 흔드는 사람 모양'), 禺(遇 '원숭이 모양'), 堇(難·僅 '진흙 근'), 并(併), 匸(区), 勺(約·的), 艮(限·根·銀 등) 기존 카드와 같음.
- 읽기: 전부 앱 음독·훈독에 있음(花瓶 かびん·漢字 かんじ·電灯 でんとう 등은 그 한자 음독 그대로). 받침·ㅎ 규칙 15곳 전부 실제로 맞음. 瓶 병→びん은 규칙 없이 씀(맞는 처리).
- 가타카나 0, hook 전부 '모습'으로 끝남, 캡션 길이 초과 없음.

## k2a06 (23장)

validate: 처음 오류 0 · 주의 0 → 고친 뒤에도 오류 0 · 주의 0.
축소판 p0~p5 전부 확인(23장).

### 고친 카드
- 絹 — 肙의 月을 '달 월'로 씀. 肙 = 口 + 肉(작은 벌레, 肉부)이라 원래 肉 → '육달월' + note "원래 肉(고기 육) · 여기선 누에의 통통한 몸". 장면('통통한 몸')이 육달월 뜻(몸·살)과 오히려 더 맞음. 경로 `肙/月` → `s:10-13`(같은 획, 이름표 '달 월' 주의를 피하는 기존 際·察·然 방식). 다시 그려 확인.
- 褒 — snd "保 = ほう → 褒도 ほう": 保의 상용 음독은 ほ(保険·確保)이고 ほう는 표외 음이라 학습자에게 틀린 읽기를 심을 수 있음 → "保 = ほ → 褒는 길게 ほう". tree의 保 읽기 r도 ほう → ほ(2곳). 다시 그려 확인.

### 작성자 의문 판정
- 叟 '늙은이 수': 유지(도구는 '어른 수, 쌀 씻는 소리 수'). '늙은이/어른'은 같은 뜻(노인)의 훈이고 한국 사전 관례 표기가 '늙은이 수'. 영어 풀이 old man, 일본 훈 おきな와도 맞고 장면(할아버지)에 맞음. 기존 카드에 叟 없음. 온라인 한국 사전 직접 확인은 못 함(아래).
- 侯 '과녁 후': 유지. libhangul 첫 훈이 '과녁 후'(다음 '벼슬이름 후'). 원래 뜻(과녁)이라 장면과 맞고, 기존 候 카드의 '과녁판 모양'과도 이어짐.
- 畳 첩→じょう · 嬢 양→じょう의 받침 규칙: 유지. 받침 부분(ㅂ→う, ㅇ→う)은 실제로 맞고 첫소리는 규칙으로 말하지 않음 — 金 샘플 確("확 → かく (받침 ㄱ은 く로)", 첫소리 ㅎ→か는 말 안 함)과 같은 방식. k2a04 泣(읍→きゅう)도 같은 경우로 유지.
- 絹 月 = 달 월: 고침(위). k2a04 湖(胡의 月)도 같은 기준으로 고침.
- 鉛(八 = 연필 끝) · 漬(貝 = 단지): 유지. 지침이 허용하는 모양 연상이고 note가 "여기선 ~"으로 어원을 단정하지 않음. 漬의 위쪽 '가시'는 실제 어원(朿 가시)과도 맞고, 鉛은 앱 단어 鉛筆로 바로 이어짐.

### 고치지 않았지만 약한 카드
- 呂 — p1 캡션에 '삐침 별(丿)'이 있지만 그림은 👄×2뿐. 작은 한 획이라 유지.
- 痩 — 병상에서 일어난 할아버지가 바지를 붙잡는 장면. 병·노인이 나오지만 '헐렁~' 하는 가벼운 장면이라 유지.
- 嬢 — '드레스 입고 인사하는 아가씨'는 단어 뜻(お嬢さん) 그대로라 고정관념 문제는 아니라고 봄.

### 확인 사항
- 이름 통일: 責(積·績 '가시 모양'+'조개 패' → '꾸짖을 책'), 翟(曜·躍 '꿩 적'), 弗(費 '아닐 불', $ 모양), 京(景·就·影 '서울 경'), 侯(候 '과녁판 모양'), 且(畳 note '층층이 쌓인 모양' = 組) 기존 카드와 같음.
- 읽기: 전부 앱 음독·훈독에 있음. 灰皿 はいざら·お風呂 おふろ·鉛筆 えんぴつ·帽子 ぼうし는 단어로 표시. 皿·匂의 '훈독으로 읽어요' 문장은 지침 형식 그대로.
- 받침·ㅎ 규칙 9곳 전부 실제로 맞음.
- 가타카나 0, hook 전부 '모습'으로 끝남, 캡션 길이 초과 없음.

### 확인 못 한 것
- 叟 '늙은이 수', 菐 '번거로울 복': 온라인 한국 한자사전 페이지가 막혀(en.wiktionary·hangulhanja 叟 권한 요청 시간 초과, namu 접속 오류) 영어 풀이(old man / tedious)와 사전 관례로만 판단.
- 실제 아이패드·아이폰에서 본 것이 아니라 미리보기 렌더러(Noto 이모지)로만 확인. Emoji 13.0(🪞 🪝 🪙 🪣 🪶 🪵)은 iOS 14.2 미만에서 네모로 나올 수 있음(지침상 허용 범위).
- 회전이 ±20°를 조금 넘는 이모지 몇 곳(漬 🥒 ±30°, 糖 🥄 25°, 磨 🧹 30°, 漫 💧 ±30~40°, 枝 🌿 -25°) — 방향 의미가 없는 물건이라 그대로 둠.
