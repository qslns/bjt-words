## k2c06 (23장) — validate 오류 0, 주의 0 (고치기 전·후 모두)

### 고친 카드
- 孝 — p3: 노인(👴)을 업은 사람(🧍) 뒤로 보내 어깨 너머로 빼꼼 보이게(z순서·위치만). 전에는 노인 얼굴이 업은 사람 머리를 덮어 '머리 둘 달린 사람'처럼 보여 업은 모습이 약했음. 장면(업어 드림)은 모양(耂 위 · 子 아래)·어원과 맞아 그대로.
- 砲 — p3: hook의 '돌 공'(🪨)이 🎆 뒤에 거의 다 가려져 있었음 → 포구와 불꽃 사이 비행 경로(66,31)로 옮기고 🎆 위에 그림.

### 작성자 의문 판정
- 孝 업은 그림 약함 → 위처럼 그림만 고침(장면 유지).
- 妨 여자아이가 '못 가!' 막기 → 유지. 아이가 장난스럽게 길을 막는 능동적 장면이라 '여자 = 방해물' 고정관념으로 읽히지 않음. 뒤집으면 女가 당하는 쪽이 되고 한자에 없는 방해꾼을 새로 넣어야 해서 더 약해짐.
- 索 🪡(Emoji 13.0) → OK. 규칙(13.1 이하) 안이고 validate 통과.
- 辛 그림 글자 카드(tree [] + basic) → OK. 辛 자체가 부수(매울 신)이고 앱 카드 壁·辞·避·癖도 辛을 통째 부품 '매울 신'으로 씀.
- 威 戌 획(s:1-3,7-9) '창 모양' → OK. 같은 조각을 感(note 戌)·歳·蔵이 '창 모양'으로 부름(滅만 '개 술'). note에 戌(개 술)도 있음.
- 鉄砲 てっぽう (앱 음독은 ほう만) → OK. 단어 읽기임이 분명히 표시되어 있고 'ほう가 ぽう로 바뀌어요'로 소리 변화를 설명, 한자 읽기로 잘못 내세우지 않음.

### 고치지 않았지만 약한 편(이유)

- 鈍 — 무딘 칼로 '새싹'을 자르려는 상황이 살짝 어색하지만 '안 잘려!'로 무디다가 바로 보임.
- 准 — '은메달을 걸고'인데 🥈이 새 목이 아니라 시상대 앞에 있음. 2등 자리(준우승)는 분명해서 그대로.

### 확인한 것

## k2c07 (23장) — validate 오류 0, 주의 0

### 고친 카드
- 없음. 23장 모두 장면 = 단어 뜻, 부품·획 묶음·이름·읽기·캡션 끝(→ 앱 훈음)·그림 잘림/겹침 확인함. 실제 크기로도 縫·憎·剥·塞을 봄.

### 작성자 의문 판정
- 塞がる가 info에 없음(훈독은 ふさ(ぐ)만) → OK. snd에는 앱 읽기 ふさ(ぐ)만 쓰고 塞がる는 bridge에 단어로만(읽기 표기 없이) 나옴 — 틀린 읽기를 내세우지 않음. 어간 ふさ가 같음. (앱 자료에 ふさ(がる) 추가는 메인 세션 판단.)
- 凸凹 でこぼこ를 통째로만 보여 줌 → OK. ぼこ는 凹의 읽기가 아니라서 나누면 거짓 읽기가 됨. '통째로'라고 분명히 표시됨.
- 濁의 중간 결과 蜀 '나라 이름 촉' → 유지. 표준 훈음이고, 애벌레 쪽 훈음은 libhangul의 '촉규화벌레 촉'뿐(너무 낯섦). '애벌레 촉'은 지어낸 훈음이 됨. 2단계 note '원래 뜻은 애벌레'(설문 葵中蠶, 사실)가 그림과 이어 줌. res에는 note 칸이 없어 이 자리가 맞음.
- 攸: 앱 修 카드 '攸 유' vs 이 배치 '아득할 유' → '아득할 유' 유지. libhangul 표준 훈음(곳 유 · 아득할 유 …)이고 悠(멀 유) 뜻과 딱 맞음. 修의 '유'는 훈 없이 음만 적은 것이라 서로 모순은 아님(같은 음, 정보만 더함). 나중에 修 카드를 '攸 아득할 유'로 맞추는 걸 권함(내 배치 밖).
- 塞 획 4–10 '벽돌 쌓는 모양' → 유지. 표준 훈음 없는 조각에 KANJI_SPEC이 정한 'X 모양' 형식이고, 塞의 실제 짜임(설문: 두 손 廾 + 쌓는 재료 㠭으로 집을 메움)과 맞음(note '가운데는 쌓은 벽돌, 아래 八은 두 손'). 단, 앱 寒 카드는 모양이 같은 이 7획 조각을 '짚 더미 모양'으로 부름 — 寒은 '짚(茻)을 덮은 사람'이 어원이라 거기선 맞고, 두 조각은 현대 자형에서만 같아진 것. 塞에 '짚 더미'를 쓰면 장면·어원과 어긋나서 다른 이름이 낫다고 판단.

### 고치지 않았지만 약한 편(이유)
- 遜 — hook은 '한 발 뒤로 물러서는(辶)'인데 p3는 🙇 꾸벅(물러서는 발은 안 보임). 겸손한 '아니에요~' 핵심은 잘 보여서 그대로.
- 憎 — '목욕이 미워! 하는 고양이 마음이 찜통처럼 김을 뿜는' 문장이 조금 꼬였지만 p3(😾 + ♨️ + 🛁)가 한눈에 '미워!'를 보여 줌.
- 凸·凹 p2 — 획 단위 두 색이라 '볼록한 부분/바닥'이 깔끔히 갈리진 않음. 그림 글자라 해가 없어 그대로.

### 확인한 것
- 읽기·받침 규칙 모두 맞음(봉·증·양·동·방→う, 탁·적·록·박·색→く/き, 심·전·건·손→ん, 철→つ, 호→か행). 단어 읽기는 단어와 함께 표시.
- 앱 카드와 같은 이름: 曽 = 여덟 팔+밭 전+날 일(増·贈·僧), 屰 '거꾸로 선 사람 모양'(逆), 彔 '나무 깎을 록' = 돼지머리 계+물 수(緑·録), 戔 '해칠 잔'(残·浅·銭), 幾 = 작을 요×2+수자리 수(機), 啇 '밑동 적 · 여기선 가지 끝…'(摘), 匹·童·放·古·巾·羊·竹·寸.
- 새 이름(앱 카드에 없음, libhangul 표준 훈음): 夆 끌 봉, 戍 수자리 수(機 카드엔 있음), 瓜 오이 과, 蜀 나라 이름 촉.
