## r12 (24장: 想 控 突 流 可 旬 載 順 完 統 促 預 絡 思 室 午 準 質 欲 説 戻 談 都 輸)
validate: 오류 0 · 주의 1(説 兌 이름표) → 0

고친 카드
- 説 — tree에서 兌를 '기쁠 태'로 쓴 것이 이름표(바꿀 태)와 달라 '주의'. 중간 결과 '兌 바꿀 태', 마지막 단계 부품 '바꿀 태' + note '기쁠 열(悅)로도 써요'(info 읽기에 えつ가 있어 근거 있음)로 통일. hook·그림·mini는 그대로(형이 풀어 주니 기뻐하는 장면은 note가 이어 줌).

고치지 않았지만 약한 카드
- 載 — '긴 창(戈) 막대로 꽁꽁 묶는' 은 창으로 묶는다는 점이 좀 억지. 그래도 수레+짐 열 개=싣다가 바로 보이고 부품 셋이 다 장면에 나와서 둠. (대안: '창 열 자루를 수레에 가득 싣고 가는 모습'으로 바꾸는 방법이 있으나 p1/p3/mini를 다시 그려야 함)
- 輸 — hook이 53자·부품 4개(車·入·月·刂)에 '수레→배→먼 곳' 3단 이야기에 가까움. 俞 이름이 '짐 실은 배 모양'(정직한 X 모양)이고 p3가 수레→배로 한 장면에 보여서 둠.
- 融 — '벌레 모양 젤리'가 솥에서 녹는 장면은 엉뚱하지만 해롭지 않고(벌레 대신 젤리로 부드럽게 함) 뜻(녹다)이 바로 보여서 둠.
- 控 — 앱 훈음 '당길 공'에 맞춰 '풍선 줄 당김'으로 잡음. 일본어 뜻(삼가다·적어 두다)은 bridge가 잇는 정도.
- 預 — 앱 훈음이 '미리 예'라 장면은 '미리 맡겨 둠'. bridge가 맡기다·맡다로 이어 줌.

플래그 처리
- 想·談 '음차 의심' → 거짓 경보('상').
- 流 '확장A 㐬' → 거짓 경보(tree p·p2 color의 경로 키에만 있고 화면에 나오는 글자는 아님).
- 順·統 p3 11개 → 축소판에서 장면이 또렷함. 둠.

검수 완료: r12

## r13 (24장: 駅 階 港 花 門 若 忙 招 色 故 声 研 火 渡 易 野 茶 丈 水 教 台 風 線 土)
validate: 오류 0 · 주의 1(丈 乂 이름표) → 0

고친 카드
- 丈 — tree 乂 이름 '선 어른 모양'이 이름표(벨 예)와 달라 '주의'. 이름표대로 '벨 예' + note '풀 벨 예 · 여기선 선 어른 모양으로 봐요'(장면의 '선 어른'은 그대로).
- 渡 — p3의 🌳(x=90)가 오른쪽 가장자리에서 잘려 x=85로 옮기고 건너는 화살표도 짧게([64,36,76,36]).

고치지 않았지만 약한 카드
- 台 — 뾰족 모자(厶)·네모 무대(口)는 모양 연상일 뿐이고 p1이 빨간 삼각형·파란 네모라 밋밋함. 그래도 '무대 위에 우뚝 선 사람'이 뜻(대)과 모양에 맞아서 둠.
- 易 — 도마뱀이 몸빛을 바꾸며 '쉽지!' 하는 건 두 뜻(쉬울 이/바꿀 역)을 한 장면에 우겨 넣은 느낌. 도마뱀=바꾸다 연상이 원래 어원 설명과 같고 bridge가 무역으로 이어 줘서 둠.
- 野 — 予를 '괭이'로 본 건 순전히 모양 연상(note에 '여기선 괭이 모양으로 봐요'라고 정직하게 씀). 이모지도 곡괭이(⛏️)라 괭이와 조금 다름. 둠.
- 色 — 뱀을 보고 얼굴빛이 질리는 장면(얼굴이 🥶). 巳를 '꼬리 파'(이름표)·'똬리 튼 뱀'으로 설명해서 맞고, 약간 무섭지만 과하지 않아 둠.

플래그 처리
- 茶 snd '한국음 차 ≠ 앱 음 다' → 茶는 음이 다·차 둘 다 있고 snd가 '차(다) → ちゃ・さ'로 둘 다 적어 둠(ちゃ는 차와 대응). 둠.
- 台 snd '대 ≠ 태' → 앱 훈음이 '대 대 / 별 태'라 대·태 둘 다 있음. 거짓 경보.
- 風 '一가 부품 목록에 없음' → 거짓 경보(s:3 한 획이 실제로 있음).
- 駅·渡 p3 12·10개 → 축소판에서 장면이 또렷함. 둠.

검수 완료: r13

## r14 (24장: 五 二 則 活 普 写 真 夏 軽 拝 雑 住 短 細 歩 忘 非 封 両 慮 飲 張 旅 途)

고치지 않았지만 약한 카드

## 확인 못 한 것·남은 걱정
- 실제 크기 미리보기와 기기별 이모지 모양(아이패드/안드로이드)은 보지 못함. 축소판만 봄. 🧎·😡는 Emoji 13.1 이하(검사 통과)지만 기기마다 얼굴·방향이 조금 다름.
- 같은 부품의 이름이 다른 카드와 다를 수 있음(开 '평평할 견' vs 다른 카드 '틀 모양', 兄 '형 형' vs '맏이 형', 巴 '꼬리 파' vs '뱀 파'). validate는 이름표가 있는 부품만 잡아서, 이 셋은 내 배치 안에서는 그대로 둠(맥락이 달라 틀리지는 않음). 전체 통일은 마무리 단계에서 한 번 보면 좋음.
- gold_s_p1은 열어 보지 않음(p0으로 기준 확인).
