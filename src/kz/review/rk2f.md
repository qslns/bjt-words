## k2b11 (27장) — validate 오류 0, 주의 0
고친 카드:
- 塊 — 글은 '꼬마 도깨비', 그림은 👻라 안 맞음 → 글을 '꼬마 귀신(鬼)'으로(hook·p2 캡션·tree note·mini). 기존 앱 카드 魔·魅도 鬼 = 👻 '귀신'이라 그쪽에 맞춤(그림은 그대로)
- 磁 — 오른쪽 위 조각은 KanjiVG대로 '초두머리'(원래 艸, 번체 茲)지만 일본 글씨 모양은 丷+一이라 tree 상자와 이름이 어긋나 보임 → note에 '원래 艸(풀 초) · 여기선 丷+一 꼴' 추가(이름은 이름표대로 유지)
판단만 하고 둔 것(작성자 표시 항목):
- 磁 兹 '무성할 자' — libhangul은 茲 = 무성할 자(兹는 그 이체) → 그대로
- 宴 日을 '해처럼 환한 등불'로 — 모양 연상, 그림(🏮)과 맞음 → 그대로
- 刀 직접 그린 칼 — 축소판·실제 크기 모두 부엌칼로 또렷, 당근 자르기라 부드러움 → 그대로
- 裸 사과가 셔츠를 벗어 던짐 — 사람 없음, K2B 규칙대로 → 그대로
- 尻 꼬리 아홉 여우 엉덩이 씰룩 — 귀엽고 성적 느낌 없음 → 그대로
- 鼓 つづみ '장구 닮은 일본 북' — 모래시계꼴 손북이라 맞는 설명 → 그대로
- 이름 확인(기존 카드와 같음): 尞 모닥불 모양(僚), 尚 오히려 상(常·堂), 敝 해질 폐(弊), 呉 나라 이름 오(誤), 咼 입 비뚤어질 괘(過), 壴 북 모양(膨)
약하지만 둔 카드:
- 塔 — 탑 꼭대기에 풀(艹)이 난 설정은 부품 넣기용 덧붙임(그림은 분명)
- 寮 — 실내 모닥불은 조금 어색(尞 = 모닥불 모양이라 일관됨)
검수 완료: k2b11

## k2b12 (27장) — validate 오류 0, 주의 0
고친 카드:
- 耗 — p3 🪥는 기기마다 새 칫솔 모양이라 '털이 다 닳았다'가 글로만 있었음 → 직접 그린 칫솔(털이 사방으로 벌어진 닳은 모양) + 🦷 + '박박' + '닳았다!'로 장면이 그림에서 보이게(hook·캡션은 그대로, 칫솔 = 소모품의 대표라 장면 자체는 좋음)
- 瓦 — p2 캡션 '옛 글자: …'인데 그림은 지금 글자 색칠 → '기와 두 장이 서로 맞물린 모양'
- 隙 — 같은 단계의 小 두 개가 p2에선 둘 다 주황, tree에선 주황·파랑(렌더러가 한 단계 안 색을 서로 다르게 함) → p2 오른쪽 아래 小를 파랑으로 맞춤
판단만 하고 둔 것(작성자 표시 항목):
- 稽 — '더 맛있게! 한 번 더' 요리 연습. お料理のお稽古처럼 실제 쓰는 말이고 hook에 '연습'이 장면으로 들어 있음. 禾·尤·旨를 다 쓰면서 더 구체적인 장면은 못 찾음 → 그대로(약한 카드로 표시)
- 耗 p1 🚜 — 쟁기 이모지가 없어 '밭 가는 것'으로 이해됨 → 그대로
- 醜 — 👻가 술 단지 옆에서 딸꾹·💫, 만화풍이고 '꼴사나움(醜態)'으로 술 취함을 부정적으로 그림. 피·폭력·역겨움 없음 → 그대로. 鬼 = 👻 '귀신'은 기존 魔·魅 카드와 같음
- 隙 오른쪽 '틈새로 새는 빛 모양' — 표준 훈음 없는 조각(확장 B 글자)이라 KANJI_SPEC대로 'X 모양', 참고 어원(틈새·빛)과도 맞음 → 그대로
- 枕 冘을 '이불(冖) 덮은 사람(儿)'으로 — tree 이름은 덮을 멱·어진사람인발로 정식, 모양 연상일 뿐 어원 단정 없음 → 그대로
- 蓋 🪰 — 작은 파리를 '가!'로 쫓는 장면, 역겹지 않음(Emoji 13.0) → 그대로
- 이름 확인(기존 카드와 같음): 并 아우를 병(併·瓶), 밥식변(飯·飲·館), 桀 빼어날 걸·舛 어그러질 천·尤 더욱 우(libhangul)
약하지만 둔 카드:
- 稽 — 위와 같음
- 岬 — '거북 등딱지(甲)처럼'은 비유라 그림(곶 지도)엔 안 보임(뜻은 그림으로 분명)
