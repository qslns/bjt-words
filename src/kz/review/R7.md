# R7 검수 로그 (s05 s06 s07 s08)

## s05 (22장)
고친 카드:
- 区 — tree·p1 캡션의 乂 이름 '풀 벨 예' → 이름표대로 '벨 예'.
- 争 — tree 조각 이름 정식화: s:1-2 '위에서 잡는 손' → '손 모양'(note 위에서 잡는 손), s:3-5 '아래서 잡는 손' → '돼지머리 계'(note 여기선 손 모양 · 부수 이름 튼가로왈).
- 服 — tree의 月을 '육달월 · 원래 肉'으로 단정한 건 틀린 어원(服의 月은 원래 舟, 강희자전·일본 사전 모두 月부). '달 월' + note '원래 舟(배 주)가 변한 모양 · 여기선 몸으로 봐요'로 고침. → validate '주의'(이름표 육달월) 1건은 이 이유로 일부러 남김.
- 将 — hook 54자 → 46자로 다듬음(爪 → 실제 모양 爫), tree 丬 이름 '평상 모양'+note '평상 장'(없는 훈음) → '나무 조각 장' + note '원래 爿(장수장변) · 평상 모양'(r07과 통일), p3 '앞으로!' 글자가 머리와 겹쳐 위치 옮김.
고치지 않았지만 약한 카드:
- 似 — p1이 이모지 대신 획(亻 + 以)이고, p2가 亻·人을 같은 파랑으로 칠해 tree의 以 색(초록)과 다름. '똑같이 닮음'을 보여 주려는 의도라 둠.
- 玄 — p3에 실타래가 직접 안 보이고 솥 밖으로 검은 실 한 가닥만 보임. 캡션으로 이해는 됨.
- 区 — 匸 이름표 '상자 방(터진입구몸)'은 원래 匚의 이름(匸는 감출 혜·터진에운담). 이름표 문제라 손대지 않음.
- 勢 — hook '와르르' vs p3 글자 '우르르!'(사소).
검수 완료: s05

## s06 (22장)
고친 카드:
- 史 — tree 乂 '풀 벨 예' → 이름표대로 '벨 예'.
- 妻 — tree s:2-4(⺕) '고슴도치머리 계' → '돼지머리 계' + note '여기선 손 모양 · 부수 이름 튼가로왈'(지침 이름 통일).
고치지 않았지만 약한 카드:
- 北 — p3 직접 그린 항목 18개(자동 경보). 축소판에서 '등 맞댄 두 사람 + 북풍'으로 잘 읽혀 둠.
- 翻·廊·南·放 — p3 항목 11~15개(경보)지만 책장·복도·빨래대·양 떼로 바로 읽힘.
- 南 — hook에 괄호 부품 4개(49자)라 조금 빽빽. 丷+干을 '햇살 쬐는 빨래대 모양'이라는 중간 단계로 묶음(부품 3개 제한 때문, 'X 모양'이라 정직함).
- 顔 — tree의 '기슭 엄(厂)' 칸이 KanjiVG 나눔 때문에 한 획(丿)만 보임. note로 설명돼 있어 둠.
- 母 — hook 괄호 女는 KanjiVG 부품(毋)이 아니지만 '女 + 젖 두 점' 어원과 맞고 tree도 '여자 모양'으로 정직해 둠(경보는 거짓 경보로 판단).
- 覚 — hook '번쩍(小)'은 ⺍(つ 모양) 자리. 컴파일러도 ⺍→小로 바꾸는 관례라 둠(경보는 거짓 경보).
- 驚 — 敬 단계 mini가 '공경' 뜻이 아니라 hook 이야기(막대로 톡)라 조금 어긋남.
검수 완료: s06
