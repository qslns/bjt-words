# V2 검수 로그 (r03 r04 r08 r09)

범위: 4개 배치 96장을 한 장도 빠짐없이 다시 검수함(앞서 일부 검수된 것도 전부 다시 봄). 배치마다 validate → 파일 통째로 읽기 → 읽기(snd)를 앱 음독·훈독(kz_cards.json)과 대조 → 축소판(--sheet) 전부 보기. 고친 카드는 고친 뒤 다시 그려서 확인. 고치기 전 백업과 비교해 고친 카드 말고는 바뀐 곳이 없음을 확인함(r03·r09는 바이트까지 그대로, r04·r08은 파일 형식 그대로).

공통으로 확인 못 한 것
- 실제 크기 그림으로 본 카드는 成·速·厳뿐이고 나머지는 축소판으로 봄. 아주 작은 겹침·잘림은 놓쳤을 수 있음.
- 드문 한자(丩 収, 覀 価, 咼 過, 廾 展, 卬 迎)가 iPad에서 실제로 나오는지는 기기로 못 봄. 전부 기본 한자 영역(확장A 아님)이라 시스템 글꼴 대체로 나올 것으로 판단.
- 네 배치의 눈에 보이는 글자 전부 스캔: 확장A·B, 호환 한자, 사용자 영역 글자, 가타카나(・ー 제외) 0. 영문자 0.

## r03 (24장: 報 件 資 成 応 任 現 収 給 限 価 税 設 得 言 心 訳 止 遅 続 特 国 過 消)
validate: 오류 0 · 주의 0 (처음부터 0, 고친 것 없음)

고친 카드
- 없음. 읽기·훈음·이름표·장면 모두 기준 안.

고치지 않았지만 약한 카드
- 件 — hook '한 건, 두 건!'이 한국음 '건'을 세는 말로 쓴 말놀이에 가까움. 件이 실제로 건수를 세는 글자(一件·用件)이고 소를 한 마리씩 세는 그림이 또렷해서 둠.
- 遅 — 느림보 양을 탄 사람이 약속에 늦는 장면은 엉뚱함. 그림이 또렷하고 '늦었다!' 뜻이 바로 보여서 둠.
- 収 — hook 괄호의 丩(갈고리 막대)는 드문 글자. tree 이름은 정직한 '갈고리 막대 모양'(丩는 libhangul에도 훈 없이 음 '구'만 있음)이고 당겨 거두는 그림이 뜻을 보여 줘서 둠.

플래그 처리
- 成 hook 괄호 戊 '부품 목록에 없음' → 거짓 경보에 가까움. 成은 戊 모양 속에 丁 획이 들어간 글자라 tree가 획 묶음(s:1-2,4-6 '다섯째 천간 무' + s:3 '장정 정')으로 쪼갬. 실제 크기 그림에서 p2·tree 색이 맞는 것 확인.
- 収 丩 '부품 목록에 없음' → 위 약한 카드 항목과 같은 이유로 둠.
- 得 '확장A 글자 㝵' → 거짓 경보. 㝵는 tree의 KanjiVG 경로 이름(p 칸)에만 있고 화면 글자로는 안 나옴(부품은 획 그림). hook·캡션·이름·mini·snd에는 없음.
- 価 p3 10개·続 p3 10개·特 p1 11개/p3 16개 → 축소판에서 천막 가게·줄에 걸린 옷·소 떼 장면이 또렷해 둠. (特 p3은 15개를 넘지만 소 떼 속 빛나는 한 마리가 한눈에 보임.)

검수 완료: r03

## r04 (24장: 食 値 着 有 達 落 改 示 展 基 連 客 工 仕 世 終 車 速 席 注 相 作 近 初)
validate: 오류 0 · 주의 0 (처음부터 0, 고친 뒤도 0)

고친 카드
- 値 — tree 1단계 셋째 부품 이름 'ㄴ자 획' → '새 을' + note 'ㄴ자 모양'. 이름표(乚=새 을)와 r01 直 카드의 이름에 맞춤(s: 경로라 검사기가 못 잡은 것).
- 速 — p3 그림에서 나뭇단이 달리는 사람과 따로 놀아 hook '나뭇단을 한 아름 안고'가 안 보였음 → 사람이 나뭇단을 안고 뛰는 그림(바람·'쌩~')으로 다시 그리고 캡션 '쌩~ 달려가요' → '나뭇단 안고 쌩~ 달려가요 → 빠를 속'. 실제 크기·축소판으로 다시 확인.

고치지 않았지만 약한 카드
- 達 — 양이 흙길을 올라 깃발에 '도달!'하는 장면은 앱 훈음 '통달할'보다 '이르다'에 가까움. bridge가 이르다·닿다·전하다(達成·配達·友達)로 이어 주고 그림이 또렷해서 둠.
- 世 — 3대 가족사진은 훈음 '인간 세'보다 '세대'에 가까운 장면. 세대 뜻이 bridge(世代·世界·お世話)에 있고 basic은 모양만 정직하게 말해서 둠.

플래그 처리
- 値·世 bridge, 示 basic, 相 snd '일본어 음차 의심' → 모두 거짓 경보(가치·세대·보일 시의 '시'·'상'). 相의 한국음 상 → そう(받침 ㅇ → う)는 규칙이 맞음.
- 連 p3 16개 → 수레 셋이 줄지은 그림이 축소판에서 또렷해 둠.
- 어원 단정 확인: 食(뚜껑+밥그릇)·初(옷감+칼)·有(손+고기)·示(제단)·車(위에서 본 수레)는 널리 알려진 풀이와 맞음. 工은 '닮은 그림 글자'로만 말해 단정 안 함.

검수 완료: r04

## r08 (24장: 感 態 男 女 置 頃 課 答 選 係 朝 十 習 単 由 去 祝 遠 厳 院 迎 障 荷 四)
validate: 오류 0 · 주의 0 (처음부터 0, 고친 뒤도 0)

고친 카드
- 厳 — hook '언덕(厂) 위 선생님이 두 입(口口)으로 호통'은 입이 둘 달린 선생님처럼 읽혀 이상함 → '언덕(厂) 위에서 선생님 둘이 입(口口)을 모아 ‘감히(敢)!’ 호통치는 엄한 모습'. p3 그림도 언덕 위 선생님 둘 + '감히!' + 놀란 얼굴 둘로 다시 그리고, tree mini도 '두 사람이 입(口口)을 모아'로 맞춤. 실제 크기·축소판으로 확인.

고치지 않았지만 약한 카드
- 課 — 훈음 '매길 과'를 '열매 따 와!' 숙제로 풀어 조금 느슨함. 숙제 내 주기(과제)로 뜻이 이어지고 그림이 또렷해서 둠.
- 男·女 — 성별 고정관념 확인: 두 카드 모두 글자의 널리 알려진 유래(밭+힘 / 무릎 꿇은 사람)를 그대로 말하고 평가·역할 단정이 없어 둠.
- 由 — 병 그림 글자라고 단정하지 않고 basic이 '보는 설이 있어요'로 말함. 둠.

플래그 처리
- 感 bridge '음차 의심' → 거짓 경보(감사·감상의 '감').
- 置 p3 12개·選 p3 10개 → 축소판에서 장면이 또렷해 둠.
- 厳 hook 괄호 口 '부품 목록에 없음' → 厳 윗부분이 吅(입 둘)이 변한 꼴이라 생긴 경보. tree 이름 '입 둘 모양'과 note '입 둘(口口)이 변한 꼴'이 정직하게 설명해 둠.
- 迎 — 卬 '나 앙'은 표준 훈음이고, 중간 결과 이름이 '한자 + 훈음'인 것은 이 앱 카드의 공통 표기(나머지 32곳도 같음)라 그대로 둠.
- 어원 단정 확인: 態(곰 能 + 마음)·習(날개 + 흰)·男·女는 널리 알려진 풀이와 맞음.

검수 완료: r08

## r09 (24장: 優 性 右 形 留 守 働 念 楽 市 乗 起 強 深 昼 屋 元 家 道 法 卒 段 押 供)
validate: 오류 0 · 주의 0 (처음부터 0, 고친 것 없음)

고친 카드
- 없음. 읽기·훈음·이름표·장면 모두 기준 안.

고치지 않았지만 약한 카드
- 強 — 힘센 벌레가 활을 당기는 장면은 엉뚱하지만 虫·弓·厶 세 부품이 다 그림에 나오고 '으랏차!'로 뜻(강함)이 보여서 둠.

플래그 처리

- 市 p3 13개·昼 12개·道 11개 → 축소판에서 장면이 또렷해 둠.
