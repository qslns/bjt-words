# R2 검수 로그 (pa pb r01 r02 r03 r04)

## pa (6장: 定 大 人 前 来 行)
validate: 오류 0 · 주의 0 (고친 뒤 다시 확인)

고친 카드
- 前 — hook·p1 캡션·mini의 확장A 글자 䒑(아이패드에서 네모 위험, 플래그)를 일반 한자 丷(두 발 모양)로 바꿈. p1 캡션도 "발 모양(丷) + 배(舟→月) + 칼(刂)"로 정리. 축소판 다시 확인함.

고치지 않았지만 약한 카드
- 前 — 칼(刂)로 '앞으로!' 가리키는 건 조금 억지. 그래도 부품 셋이 다 장면에 나오고 '앞으로!'로 뜻이 바로 보여서 둠.

플래그 처리
- 来 '一가 부품 목록에 없음' → 거짓 경보(1획 가로획 s:1이 실제로 있음, 来 = 一 + 米 모양).

검수 완료: pa

## pb (6장: 通 取 事 業 期 時)
validate: 오류 0 · 주의 1 → 0 (事 이름표)

고친 카드
- 事 — tree ⺕ 이름 '손 모양' → 이름표대로 '돼지머리 계' + note '여기선 손 모양 · 부수 이름 튼가로왈'(validate 주의 해결).
- 業 — tree 2단계(선반 판자 모양+나무 목 = '나무 가판대 모양' → 물건+가판대)가 지어낸 '모양' 중간 조각을 하나 더 만들고 있어서, 한 단계 3부품(늘어선 물건 모양 + 선반 판자 모양 + 나무 목 = 업 업)으로 줄임. p2 캡션(위·가운데·아래)과도 맞음.

고치지 않았지만 약한 카드
- 期 — p3 항목 15개(직접 그린 달력)지만 축소판에서 '탁자 위 달력에 동그라미'가 또렷해서 둠.
- 時 — p1 11개·p3 13개(직접 그린 절)지만 절·종·해가 잘 보여서 둠.
- 業 — p3 10개, 가판대 장면 또렷함. 둠.

검수 완료: pb

## r01 (24장: 先 年 急 送 後 今 所 用 度 売 本 料 月 話 直 受 半 立 向 対 者 正 支 申)
validate: 오류 0 · 주의 0 (처음부터 0, 고친 뒤도 0)

고친 카드
- 年 — hook 괄호 (禾)(人)는 지금 年 모양 안에 없는 옛 글자 부품이라(플래그) 괄호를 빼고 "벼를 짊어진 사람이 …"로. p3 그림 글자 '올해도 풍년!' → hook과 같은 '올해 농사 끝!'. (옛 글자 설명은 p1·basic에 그대로 있음)
- 急 — tree s:3-5 이름 '손 모양' → 이름표대로 '돼지머리 계' + note '여기선 손 모양 · 부수 이름 튼가로왈'(s: 경로라 검사기가 못 잡은 것).
- 所 — snd가 '훈독 ところ(場所 ばしょ)'로 음독 예(ばしょ)를 훈독 예처럼 붙여 놓아 틀림 → "しょ(場所 ばしょ · 住所 じゅうしょ) · 훈독 ところ".
- 料 — 말(斗)로 퍼면서 '한 되, 두 되!'로 세는 단위 섞임 → '한 말, 두 말!'(hook·p3 캡션·p3 그림 글자·mini). p1 캡션 '국자 모양 되' → '국자 모양'.

고치지 않았지만 약한 카드
- 先 — hook '발(止)': 先 위쪽은 止가 변한 모양이라 止 그대로는 아님(플래그). p1 캡션·tree note가 '止가 변한 것'이라고 바로 설명해서 둠.
- 直 — '(乚)'은 마지막 ㄴ자 한 획. 이름표 乚=새 을이라 tree 이름도 맞음. 'ㄴ자 자로 곧은지 재기' 장면이 좋아서 둠(플래그는 부품 목록에 획이 따로 없어서 생긴 것).
- 後·向 — 지어낸 중간 조각 하나씩('실에 걸린 발 모양', '지붕 달린 집 모양'). KanjiVG 묶음 그대로이고 이름이 정직한 'X 모양'이라 둠.
- 者 — '내가 그 사람이오!'로 '사람' 뜻을 대사로만 보여 줌. 놈 자는 그림으로 잡기 어려운 뜻이라 둠.
- 今 — '지금 여기!'도 대사로 뜻을 보여 주는 편. 둠.
- 立 — 丷(V 모양)을 '벌린 두 다리'로 봄. 옛 글자(大)에 근거한 연상이라 둠.
- 申 — 앱 훈음 '거듭 신'과 장면(신청)이 다름. 지침대로 단어 뜻(申し込み·申請) 쪽 장면이고 bridge가 이어 줘서 둠.

플래그 처리
- 向·対 bridge '음차 의심' → 거짓 경보('향상', '대상'의 '상').
- 売 p3 10개 → 천막 가게 장면 또렷함. 둠.

검수 완료: r01
