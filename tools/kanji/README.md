# 한자 암기 단원 자료 (10/15)

- `mn/001.tsv` … `mn/007.tsv`: 950자 그림 연상 (`한자<TAB>연상`). 형식: `그림 → «한국 음»! 소리 놀이(히라가나)`.
- 순서: 기본 885 + 본편 1–1500 단어에 그 한자가 나오는 단어 수 많은 순(같으면 공부 순서 먼저).
- `kanji_src.py`: 단어 데이터에서 한자별 읽기(음독은 히라가나, 훈독은 어간(오쿠리가나))·단어 목록을 만든다.
- `build_kj.py`: 연상 + 읽기 + 단어 → 앱 데이터(`kanji_app.json`). «음»이 한자 음과 맞는지, 가타카나가 없는지 검사하고 틀리면 멈춘다.
- `qa_mn.py`, `translit_check.py`: 연상 속 히라가나 읽기·한글 음차 검사.
