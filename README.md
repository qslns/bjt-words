# BJT 단어 회독 (아이패드 홈 화면 앱)

BJT에 나오는 비즈니스 일본어 3,817단어를 회독 방식으로 외우는 단어장입니다. 번호가 앞일수록 BJT 핵심 단어입니다. 1~1,500번이 핵심(S·A 등급)이고, 그 뒤는 N3~N1 일반 어휘를 모은 보험용입니다. 설치형 웹앱(PWA)이라 아이패드 홈 화면에 앱처럼 추가해서 씁니다.

## 아이패드에 설치

1. 아이패드 **Safari**로 앱 주소를 엽니다.
2. 공유 버튼(네모에 위 화살표) → **홈 화면에 추가** → 추가.
3. 이제 홈 화면의 **BJT 단어** 아이콘으로 엽니다. 주소창 없이 전체 화면으로 열리고, 한 번 연 뒤에는 인터넷 없이도 됩니다.

## 공부 방법

- **가볍게 1회독**: 처음부터 끝까지 한 번씩만 봅니다(반복 없음). 카드마다 부수 → 한자 → 단어 이야기, BJT 포인트, 예문, 발음이 한 화면에 나옵니다.
- **회독 장**: 250개 묶음 안에서 50개씩 늘려 가며 알고있음/모르겠음으로 넘기고, 모르는 단어는 장 끝에서 다 맞힐 때까지 반복합니다. 500개마다 총정리 장이 있습니다.
- **소리로 맞히기**: 학습 화면 위의 **소리** 버튼을 켜면 글자 없이 발음만 듣고 뜻을 떠올립니다(청해 연습).

## 저장

- 진도는 그 아이패드의 앱 안에 자동 저장됩니다. Safari 탭과 홈 화면 앱은 저장 공간이 따로입니다.
- 앱을 지우거나 기기를 바꾸기 전에 **설정 › 진도 백업 · 옮기기 › 내보내기**로 코드를 받아 두세요. 다른 기기에서 **가져오기**에 붙여넣으면 이어집니다.

## 발음

- 단어 3,817개와 예문 7,914개를 Microsoft 신경망 일본어 음성(여성 Nanami, 남성 Keita)으로 미리 녹음해 `audio/`에 넣었습니다. 기기 음성은 녹음 파일을 못 불러올 때만 대신 씁니다.
- **설정 › 발음 › 음성 전체 받아두기**(약 190MB, 와이파이 권장)를 한 번 하면 인터넷 없이도 발음이 나옵니다. 이미 받아 둔 음성은 다시 받지 않습니다.

## 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 전체(단어 3,817개·한자 1,277자 데이터 포함) |
| `sw.js` | 오프라인 캐시 (녹음 음성 포함) |
| `audio/w/<번호>.mp3`, `audio/s/<번호>-<예문>.mp3` | 단어·예문 녹음 |
| `manifest.webmanifest`, `icons/` | 홈 화면 아이콘·이름 |
| `vercel.json` | Vercel로 올릴 때의 캐시 설정 (GitHub Pages에서는 쓰지 않음) |
